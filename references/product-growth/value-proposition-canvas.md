# Value Proposition Canvas

## Core Concept
Two-part fit validation: Customer Profile (Jobs, Pains, Gains) ↔ Value Map (Products/Services, Pain Relievers, Gain Creators). When the two parts achieve fit, you have product-market fit evidence.

## Applicable Scenarios
✅ **Best for**
- PMF (Product-Market Fit) validation
- Feature prioritization
- Differentiated positioning

⚠️ **When NOT to use**
- Desk-fit exercises — filling both circles from internal opinion then declaring fit; every pain and gain must trace to customer evidence (**The Mom Test** for interviews, **JTBD** for job statements)
- Ranking a large backlog — the canvas shows gaps, not ordered bets; combine with impact/effort or **Kano** for prioritization
- Exhaustive lists — 25 pains with equal weight is not analysis; force the top 2-3 per block in the customer's own ranking
- Claiming PMF — fit on paper is hypothesis, not evidence; pair with experiments before building

## Key Steps
1. **Customer Profile**: List customer Jobs (functional/social/emotional), Pains (before/during/after the job), Gains (expected/desired/unexpected outcomes)
2. **Value Map**: List your Products/Services, how each relieves specific Pains, how each creates specific Gains
3. Assess fit: does each Pain have a reliever? Does each Gain have a creator?
4. Identify gaps: pains without relievers, gains without creators
5. Prioritize features to close the biggest gaps
6. Validate with customer interviews

## Output Template

```
Segment: [segment]  Evidence: [# interviews / data sources]
Customer Profile
  Jobs: [functional / social / emotional — ranked by importance]
  Pains: [top 2-3, ranked by severity]
  Gains: [expected / desired / unexpected — ranked]
Value Map
  Products/Services: [list]
  Pain relievers: [which reliever kills which pain — explicit pairing]
  Gain creators: [which creator delivers which gain — explicit pairing]
Fit gaps: [pains without relievers / gains without creators]
Priorities: [features closing the biggest gaps]
Validation: [interview or experiment plan for the top gap]
```

## Failure Modes
- Self-referential fit: the team writes both circles and celebrates alignment → require evidence per item, mark unverified ones, and treat unvalidated fit as a hypothesis map
- Pain/gain inflation: exhaustive lists dilute focus → force-rank to the top 2-3 per block; customers don't experience 25 pains equally
- Pairing theater: drawing a reliever next to a pain doesn't make it relieve → validate each pairing in interviews; weak relievers create fit illusions
- Canvas as conclusion: fit on paper treated as PMF evidence → the canvas generates hypotheses; demand must be validated with experiments before build

## Evidence Strength
Practitioner consensus — a standard lean-startup and design tool that structures hypothesis formation well; its limitation is that canvas "fit" is not validated demand — the evidence value depends entirely on whether the customer profile side is grounded in real customer research rather than internal assumption.
