# Value Proposition Canvas

## Core Concept
Two-part fit validation: Customer Profile (Jobs, Pains, Gains) ↔ Value Map (Products/Services, Pain Relievers, Gain Creators). When the two parts achieve fit, you have product-market fit evidence.

## Applicable Scenarios
✅ **Best for**
- PMF (Product-Market Fit) validation
- Feature prioritization
- Differentiated positioning

## Key Steps
1. **Customer Profile**: List customer Jobs (functional/social/emotional), Pains (before/during/after the job), Gains (expected/desired/unexpected outcomes)
2. **Value Map**: List your Products/Services, how each relieves specific Pains, how each creates specific Gains
3. Assess fit: does each Pain have a reliever? Does each Gain have a creator?
4. Identify gaps: pains without relievers, gains without creators
5. Prioritize features to close the biggest gaps
6. Validate with customer interviews

## Source
Alexander Osterwalder et al., *Value Proposition Design* (2014).
