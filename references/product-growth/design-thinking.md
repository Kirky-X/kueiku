# Design Thinking

## Core Concept
Human-centered design loop: Empathize → Define → Ideate → Prototype → Test. A non-linear, iterative process for creative problem solving that keeps the user at the center.

## Applicable Scenarios
✅ **Best for**
- New product 0-to-1 design
- Service design
- Innovation workshops

## Key Steps
1. **Empathize**: conduct user interviews, observations, immerse in user context
2. **Define**: synthesize findings into a clear problem statement (point of view)
3. **Ideate**: generate many solutions (diverge), then select promising ones (converge)
4. **Prototype**: build quick, low-fidelity prototypes of top ideas
5. **Test**: put prototypes in front of users, learn, iterate
