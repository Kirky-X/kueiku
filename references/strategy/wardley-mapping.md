# Wardley Mapping · 沃德利地图

## 核心理念

战略不是静态快照，而是动态演化。Wardley Mapping 通过价值链（纵轴）× 演化阶段（横轴）两个维度，可视化组件的战略地形，指导差异化决策。

> "地图不是领土，但没有地图你会迷路。" —— Simon Wardley

## 适用场景

✅ **最适合**
- 战略演化感知——理解行业正在向哪里演变
- Build vs Buy vs Outsource 决策
- 识别战略性技术投资时机
- 竞品动态分析与差异化定位
- 价值链中各环节的演化差异

⚠️ **慎用**
- 全新市场（无价值链参考，用 Lean Canvas / Blue Ocean）
- 只需静态竞争分析（用 Porter's Five Forces 更简单）
- 团队不具备战略感知基础（先学 Value Chain Analysis）

## 执行步骤

### Step 1：确定用户需求（锚点）

所有地图从用户需求出发——没有需求，价值链无从建立。

```
关键问题：
  终端用户是谁？
  他们的核心需求是什么？（用 JTBD 描述）
  需求的满足度如何？

输出：
  1-3 个核心用户需求作为地图的"北方"（最上方）
```

### Step 2：绘制价值链（纵轴）

从用户需求向下分解，列出满足需求所需的所有组件。

```
价值链层级：
  用户需求（最顶层）
    ↓
  产品/服务（满足需求的直接交付物）
    ↓
  关键组件（构成产品的核心模块）
    ↓
  基础设施（支撑组件的底层能力）
    ↓
  数据/内容（流动在系统中的信息）

标注方式：
  每个组件用节点表示
  组件间用连线表示依赖关系
  纵轴从上到下 = 从用户可见到不可见
```

### Step 3：标注演化阶段（横轴）

每个组件在横轴上标注其当前演化阶段。

```
演化阶段（从左到右）：
  Genesis（创世）   → 独特/未知/正在探索（如 AGI、量子计算应用）
  Custom-Built（定制）→ 为特定场景定制开发（如企业内部系统）
  Product（产品）   → 标准化产品，有明确用户群（如 SaaS 产品）
  Commodity（商品） → 标准化、可替换、价格驱动（如云计算、数据库）

判断信号：
  Genesis    → 无标准 API、每次实现不同、无市场定价
  Custom     → 有 API 但需定制集成、供应商锁定
  Product    → 标准 API、明确定价、可比较功能
  Commodity  → 完全标准化、价格竞争、可即插即用、效用模式（按量付费）
```

### Step 4：标注竞品位置

在地图上标注主要竞品的组件位置。

```
标注内容：
  竞品的组件在哪个演化阶段？
  竞品是否在某些环节做了差异化？
  竞品的价值链结构与你有什么不同？

洞察来源：
  竞品在 Genesis/Custom 阶段的组件 → 可能是他们的差异化来源
  竞品已推向 Commodity 的组件 → 你也可以考虑商品化以降低成本
```

### Step 5：制定战略动作

根据组件所处演化阶段选择策略。

```
演化阶段 → 战略方法：
  Genesis    → 创新策略：探索、实验、接受失败（搭配 Lean BML / Design Thinking）
  Custom     → 差异化策略：定制化、快速迭代、贴近用户（搭配 JTBD / VPC）
  Product    → 竞争策略：功能对比、定价、渠道（搭配 Porter's / Positioning）
  Commodity  → 效率策略：成本优化、外包、标准化（搭配 Value Chain Analysis）

关键战略动作：
  加速演化：推动组件向商品化移动（降低自身成本）
  差异化定位：在 Genesis/Custom 阶段建立壁垒
  战略取舍：判断哪些组件值得投入，哪些应该商品化
```

## 常见陷阱

| 陷阱 | 避免方式 |
|------|---------|
| 混淆演化阶段——把 Product 当 Commodity | 用判断信号逐条验证，不要凭直觉 |
| 忽视价值链层级——扁平化所有组件 | 保持 3-5 层层级结构 |
| 只画当前状态不思考演化方向 | 为每个组件标注"演化方向箭头" |
| 地图太复杂——包含所有组件 | 聚焦 15-25 个关键组件，其余省略 |
| 把地图当一次性产出 | 每季度更新，跟踪演化变化 |

## 与其他方法论的关系

- **搭配 Value Chain Analysis**：价值链分析提供组件分解基础，Wardley Mapping 增加演化维度
- **搭配 Technology Adoption Lifecycle**：Gartner Hype Cycle 描述需求侧的技术感知，Wardley 描述供给侧的组件演化
- **搭配 Blue Ocean Strategy**：蓝海战略寻找价值创新方向，Wardley 提供地形分析工具
- **搭配 BCG Matrix**：BCG 做产品组合管理，Wardley 做组件级战略感知
- **搭配 Porter's Five Forces**：Porter's 分析行业竞争结构，Wardley 分析价值链内各组件的演化动态
