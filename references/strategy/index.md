# Strategic Analysis · 战略分析

**适用场景**：需要评估整体形势、制定方向性决策

| 方法论 | 一句话描述 | 最佳场景 | Reference |
| --- | --- | --- | --- |
| **SWOT** | 内部优劣势 × 外部机遇威胁的四象限评估 | 年度规划、产品上市、战略转型 | `swot.md` |
| **PESTLE** | 六维宏观环境扫描 | 进入新市场、政策影响分析、外部风险评估 | `pestle.md` |
| **Porter's Five Forces** | 竞争格局五力模型 | 行业进入判断、竞争策略制定 | `porter-five-forces.md` |
| **Business Model Canvas** | 9模块完整商业模式设计与评估 | 创业/转型/竞品商业模式分析 | `business-model-canvas.md` |
| **Stakeholder Mapping** | 影响力×利益矩阵，识别并管理所有关键相关方 | 组织变革、跨部门项目、政策落地 | `stakeholder-mapping.md` |
| **Ansoff Matrix** | 现有/新市场 × 现有/新产品的四象限增长策略 | 增长方向选择、市场扩张、多元化决策 | `ansoff-matrix.md` |
| **Blue Ocean Strategy** | 价值创新跨越竞争，开创无人争抢的市场空间 | 非竞争性增长、战略差异化、红海突围 | `blue-ocean.md` |
| **McKinsey 7S** | 战略/结构/制度/人员/技能/风格/价值观 七维组织诊断 | 组织能力评估、内部一致性检查、变革阻力分析 | `mckinsey-7s.md` |
| **BCG Matrix** | 市场增长率 × 相对份额 的四象限产品组合管理 | 产品投资分配、组合平衡、业务取舍 | `bcg-matrix.md` |
| **Product Strategy Canvas** | 9 段式战略画布：Vision/Segments/Value Prop/Trade-offs/Can't-Won't | 战略显性化、可被挑战的 1 页战略文档 | `product-strategy-canvas.md` |
| **Lean Canvas** | BMC 的创业适配版 9 模块（Problem/Solution/Unfair Advantage） | 早期创业商业模式 30 分钟验证 | `lean-canvas.md` |
| **Startup Canvas** | 9 段战略 + Cost Structure + Revenue Streams，分离战略与商业模式 | 早期创业需同时回答战略与盈利模式 | `startup-canvas.md` |
| **JDB Value Proposition** | 6 段 JTBD 模板：Who/Why/What before/How/What after/Alternatives | 写 PRD/官网前沉淀可被 challenge 的价值主张 | `jdb-value-proposition.md` |
| **Monetization Strategy** | 7 种变现模型：Freemium/Subscription/Usage/Seat/One-time/Marketplace/Ads | 商业模式选型、变现效率优化 | `monetization-strategy.md` |
| **Pricing Strategy** | Van Westendorp PSM + value metric + tier design | 定价/调价、价格敏感度测算 | `pricing-strategy.md` |
| **Can't-Won't Defensibility** | 竞品 can't 或 won't 的护城河策略集 | 投资人问"竞品抄你怎么办"、护城河设计 | `cant-wont-defensibility.md` |
| **Porter Diamond Model** | 国家竞争优势四要素+两大变数 | 跨国选址、产业政策、国家竞争力分析 | `porter-diamond-model.md` |
| **GE-McKinsey Matrix** | 行业吸引力×业务实力 9 格矩阵（BCG 升级版） | 多元化业务组合管理、SBU 资源分配 | `ge-mckinsey-matrix.md` |
| **Strategic Group Mapping** | 行业内战略相似企业群组与移动壁垒 | 行业竞争结构分析、新进入者定位、战略差异化 | `strategic-group-mapping.md` |
| **Value Chain Analysis** | 主活动+支持活动逐环节识别竞争优势来源 | 竞争优势诊断、成本领先/差异化策略、流程优化 | `value-chain-analysis.md` |
| **Benchmarking** | 对标行业/跨行业最佳实践识别差距 | 绩效提升、流程改进、最佳实践学习 | `benchmarking.md` |
| **Product Life Cycle** | 导入/成长/成熟/衰退 4 阶段匹配策略 | 产品策略、投资时机、组合管理 | `product-life-cycle.md` |
| **VRIO Framework** | 价值性/稀缺性/不可模仿性/组织化 四问资源观 | 资源能力评估、可持续竞争优势识别 | `vrio.md` |

## 各方法论最低信息需求

- **SWOT / PESTLE**：需要明确分析对象（产品/公司/市场）
- **Business Model Canvas**：需要明确分析对象（哪家公司/产品）
- **Ansoff Matrix**：需要明确的当前产品范围和市场范围
- **Stakeholder Mapping**：需要明确项目/决策范围
- **Blue Ocean Strategy**：需要当前行业的竞争因素认知
- **McKinsey 7S**：需要明确的组织/团队范围
- **BCG Matrix**：需要各产品的市场增长率和相对市场份额数据
- **Product Strategy Canvas**：需要团队对 9 段战略的初步思考
- **Lean Canvas**：需要早期商业模式假设 + 联合创始人对齐
- **Startup Canvas**：需要战略思考 + 成本/收入结构数据
- **JDB Value Proposition**：需要明确的客户 + 替代方案认知
- **Monetization Strategy**：需要产品形态 + 单位经济数据
- **Pricing Strategy**：需要可触达用户做 PSM 调研 + value metric 候选
- **Can't-Won't Defensibility**：需要竞品认知 + 自身资源清单
- **Porter Diamond Model**：需要目标国家/产业的四要素数据
- **GE-McKinsey Matrix**：需要各 SBU 的行业吸引力与业务实力多因素数据
- **Strategic Group Mapping**：需要行业内主要企业的战略变量数据
- **Value Chain Analysis**：需要企业各环节成本与价值数据 + 对手对比
- **Benchmarking**：需要可获取的标杆对象数据（至少 2 个独立来源）
- **Product Life Cycle**：需要产品销售/竞争/客户构成趋势数据
- **VRIO Framework**：L1：企业的资源/能力清单；L2：竞争对手对比数据

## 常见组合

- **战略规划**：PESTLE → SWOT → OKR
- **商业模式设计**：PESTLE/Porter's → Business Model Canvas → Value Proposition Canvas
- **竞争分析**：Porter's Five Forces → SWOT → First Principles
- **组织变革**：Stakeholder Mapping → 六顶思考帽 → OKR
- **增长策略制定**：Cynefin（判断问题域）→ Ansoff Matrix（选方向）→ Blue Ocean（差异化）
- **产品组合优化**：BCG Matrix（组合分类）→ Ansoff Matrix（增长方向）→ RICE（执行排序）
- **组织能力诊断**：McKinsey 7S（内部一致性）→ SWOT（内外匹配）→ OKR（改进目标）
- **竞争优势诊断**：Value Chain Analysis → Benchmarking → VRIO
- **多元化组合管理**：BCG Matrix（初筛）→ GE-McKinsey Matrix（深度评估）→ Ansoff（增长方向）
- **行业竞争结构分析**：Porter's Five Forces（整体）→ Strategic Group Mapping（内部群组）→ Blue Ocean（突围方向）
- **产品阶段策略**：Product Life Cycle（定位阶段）→ BCG Matrix（组合配比）→ OKR（阶段目标）
