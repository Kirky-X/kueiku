# Blue Ocean Strategy

## Core Concept
Value innovation: simultaneously pursue differentiation and low cost to create uncontested market space.

## Applicable Scenarios
✅ **Best for**
- Non-competitive growth, strategic differentiation, red ocean breakthrough

⚠️ **When NOT to use**
- Your market has strong network effects and the winner is already entrenched — escaping competition is rarely available
- The "uncontested space" is unproven demand you cannot cheaply test first
- Regulated or commodity markets where the ERRC levers are not yours to pull

## Key Steps
1. Map the current competitive landscape (red ocean)
2. Apply ERRC grid: Eliminate / Reduce / Raise / Create
3. Design the new value curve
4. Validate: is the blue ocean commercially viable?
5. Build the business model to deliver the new value

## Output Template

```
Current industry competing factors: [price, feature X, service Y, ...]

ERRC grid:
  Eliminate — [factor the industry races on that buyers don't value] → [savings redeployed to:]
  Reduce    — [over-designed factor]                                → [down to what level]
  Raise     — [underinvested factor buyers do value]                → [up to what level]
  New value curve: [one sentence — what buyers get that no one offers]

Viability check: [who pays, how much, why incumbents won't follow immediately]
Next validation step: [cheapest test of demand for the new curve]
```

## Failure Modes
- Blue ocean that was a puddle: "no competitors" because there is no demand → validate buyer pull before building the model
- Differentiation claimed, cost never actually removed → the ERRC grid fails unless Eliminate/Reduce genuinely fund Raise/Create
- Imitation unmodeled: oceans turn red → name what delays copying (scale, brand, switching costs) and for how long

## Evidence Strength
Contested — the book's headline cases are retrospective selections, and academic reviews question how often true uncontested spaces occur and persist; the ERRC grid itself is a useful reframe independent of the statistics.

## Source
W. Chan Kim & Renée Mauborgne, *Blue Ocean Strategy* (2005).
