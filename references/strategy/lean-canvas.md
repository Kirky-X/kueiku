# Lean Canvas

## Core Concept
BMC adapted for startups: Problem, Solution, Key Metrics, Unfair Advantage, Customer Segments, Value Proposition, Channels, Cost Structure, Revenue Streams.

## Applicable Scenarios
✅ **Best for**
- Early-stage startup 30-minute business model validation

⚠️ **When NOT to use**
- Post-product/market fit scaling — blocks like "Problem" are settled; switch to full BMC or an operating plan
- The canvas would be filled from imagination for a market you can't reach to interview — validate demand channels first
- Complex multi-sided platforms where 9 boxes must split per side — one canvas will average away the dynamics

## Key Steps
1. Fill each block (order: Problem → Customer Segments → Value Prop → Solution → Channels → Revenue → Cost → Key Metrics → Unfair Advantage)
2. Identify riskiest assumptions
3. Design experiments to validate assumptions
4. Iterate canvas based on learning

## Output Template

```
Problem (top 3)          | Customer Segments (early adopters)
  1. [pain]              |   [who feels problem #1 most acutely]
  2. [pain]              |
  3. [pain]              |
Solution (top 3 features)| Unique Value Proposition
  1-3, one line each     |   [single, clear, one sentence]
Channels                 | Revenue Streams              | Cost Structure
  [path to early adopters]| [model + price]              | [biggest items]
Key Metrics              | Unfair Advantage
  [the few that matter]  |   [something that can't be copied easily]

Riskiest assumption right now: [#1 problem truly pains early adopters] → test: [interview/landing/smallest experiment] by [date]
Canvas version: [n] — what changed since last version and why: [learning]
```

## Failure Modes
- Solution-first filling: boxes get reverse-engineered from a pet feature → fill Problem and Segments before Solution, and cap Solution at 3 lines
- Canvas as artifact: iteration stops after the first pretty version → every review must change at least one box or kill an assumption
- Unfair Advantage inflated: "passion", "first mover", "AI" — none survive contact → something not copyable for ~a year (data, distribution, expertise), else write "none yet"

## Evidence Strength
Practitioner consensus — a widely adopted adaptation of Business Model Canvas for hypothesis-driven startups; its value depends entirely on whether assumption tests actually run (the canvas itself validates nothing).
