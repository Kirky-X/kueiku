# Lean Canvas

## Core Concept
BMC adapted for startups: Problem, Solution, Key Metrics, Unfair Advantage, Customer Segments, Value Proposition, Channels, Cost Structure, Revenue Streams.

## Applicable Scenarios
✅ **Best for**
- Early-stage startup 30-minute business model validation

## Key Steps
1. Fill each block (order: Problem → Customer Segments → Value Prop → Solution → Channels → Revenue → Cost → Key Metrics → Unfair Advantage)\n2. Identify riskiest assumptions\n3. Design experiments to validate assumptions\n4. Iterate canvas based on learning

## Source
Ash Maurya, *Running Lean* (2012); adapted from Business Model Canvas.
