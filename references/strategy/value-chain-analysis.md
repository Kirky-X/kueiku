# Value Chain Analysis

## Core Concept
Primary activities + support activities, analyzing each for competitive advantage sources.

## Applicable Scenarios
✅ **Best for**
- Competitive advantage diagnostics, cost leadership/differentiation strategy, process optimization

## Key Steps
1. Map primary activities (inbound logistics, operations, outbound logistics, marketing/sales, service)\n2. Map support activities (infrastructure, HR, technology, procurement)\n3. For each activity, assess: cost and value contribution\n4. Identify activities where you have advantage or disadvantage vs competitors\n5. Develop strategy to strengthen advantageous activities

## Source
Michael Porter, *Competitive Advantage* (1985).
