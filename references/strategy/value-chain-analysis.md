# Value Chain Analysis

## Core Concept
Primary activities + support activities, analyzing each for competitive advantage sources.

## Applicable Scenarios
✅ **Best for**
- Competitive advantage diagnostics, cost leadership/differentiation strategy, process optimization

⚠️ **When NOT to use**
- Asset-light digital businesses where "inbound logistics → operations → outbound" barely describes reality — re-map activities before the template fits
- Without competitor comparison data — the chain identifies activities but advantage is always relative
- Single-process improvement — use process-specific tools; the chain is firm-scale

## Key Steps
1. Map primary activities (inbound logistics, operations, outbound logistics, marketing/sales, service)
2. Map support activities (infrastructure, HR, technology, procurement)
3. For each activity, assess: cost and value contribution
4. Identify activities where you have advantage or disadvantage vs competitors
5. Develop strategy to strengthen advantageous activities

## Output Template

```
| Activity          | Cost share | Buyer value contribution | vs competitors | Implication              |
| ----------------- | ---------- | ------------------------ | -------------- | ------------------------ |
| Inbound logistics | [x%]       | [low/med/high]           | [ahead/parity/behind] | [note]            |
| Operations        | [x%]       | [high]                   | [ahead]        | [protect and amplify]    |
| Outbound          | ...        | ...                      | ...            | ...                      |
| Marketing/sales   | ...        | ...                      | ...            | ...                      |
| Service           | ...        | ...                      | ...            | ...                      |
| Support: [tech]   | [x%]       | [enables Operations]     | [ahead]        | [advantage source]       |

Verdict: advantage lives in [activity link(s)] — strategy: [cost leadership via X / differentiation via Y]
Linkages to exploit: [activity A → B handoff where we're uniquely good]
```

## Failure Modes
- Template transplant: forcing a digital business into manufacturing vocabulary until every box is "low" → redraw the activity list for the business model first, then analyze
- Activity-by-activity myopia: optimizing each box while advantage lives in the links between them → score handoffs explicitly
- Cost-only lens: value contribution ignored, every weak-cost activity flagged for cuts → a differentiator's "expensive" activity is the moat; compare value before cutting

## Evidence Strength
Practitioner consensus — the primary/support decomposition and the linkages thesis are foundational in strategy teaching; empirical use is limited by data availability at activity granularity, so outputs are typically directional rather than audited.

## Source
Michael Porter, *Competitive Advantage* (1985).
