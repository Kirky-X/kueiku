# Can't-Won't Defensibility

## Core Concept
True moats aren't about "being better than competitors" but building barriers that competitors "can't do" or "won't do." Decompose defensibility from a vague concept into an actively designable strategy set, clearly identifying which category each moat belongs to.

## Use Cases
- Investors asking "what if competitors copy you"
- Strategic formulation phase requiring clear sustainable advantage sources
- Existing advantages being chased by competitors, needing new moats built

## Key Steps
1. List all current potential moat candidates: network effects/economies of scale/data barriers/brand/switching costs/patents/unique resources/compliance advantages
2. For each, assess which category it belongs to:
   - Can't: Competitors objectively can't do it (e.g., exclusive data/patents/compliance licenses)
   - Won't: Competitors can do it but won't (e.g., it would cannibalize their existing business model — disruptive innovation principle)
3. Verify each moat's authenticity: Does it truly take 3+ years to catch up?
4. For Can't category: Continuously strengthen (data flywheel, patent portfolio, compliance relationships)
5. For Won't category: Clarify "the cost of competitor abandonment," monitor whether they change their mind

## Source
Paweł Huryn (Product Compass); theoretical foundations in Clayton Christensen's disruptive innovation + Hamilton Helmer's 7 Powers
