# Porter's Five Forces

## Core Concept
Industry competitive structure analysis through 5 forces: Competitive Rivalry, Threat of New Entrants, Bargaining Power of Suppliers, Bargaining Power of Buyers, Threat of Substitutes.

## Applicable Scenarios
✅ **Best for**
- Industry entry assessment
- Competitive strategy formulation
- Industry attractiveness analysis

⚠️ **When NOT to use**
- Defining an entirely new category — forces describe an existing industry's structure; there are no incumbents yet
- Complementors/platform dynamics dominate (app stores, ecosystems) — the model analyzes rivalry and famously underweights cooperation
- Fast-liquidity markets where "industry" boundaries blur quarter to quarter — force ratings go stale quickly

## Key Steps
1. Assess each of the 5 forces (High/Medium/Low)
2. Identify which forces are strongest (these define industry profitability)
3. Develop strategy to position against the strongest forces
4. Monitor force changes over time

## Output Template

```
Industry: [definition + boundary]

| Force              | Level | Evidence (not vibes)                     | Trend | Implication            |
| ------------------ | ----- | ---------------------------------------- | ----- | ---------------------- |
| Rivalry            | High  | [n players, price wars, exit rate]        | [↑→↓] | [differentiate or exit]|
| New entrants       | Med   | [capex, regulation, switching costs]      |       | [raise which barrier?] |
| Supplier power     | Low   | [n suppliers, concentration, substitutes] |       |                        |
| Buyer power        | High  | [concentration, price transparency]       | [↑]   | [lock-in or scale]     |
| Substitutes        | Med   | [price-performance vs alternatives]       | [↑]   | [monitor: [X]]         |

Verdict: attractiveness [high/med/low] — structure shaped by [strongest forces]
Position: [how we handle each strong force, concrete]
Reassess trigger: [consolidation event / substitute milestone / regulation]
```

## Failure Modes
- Force ratings without evidence: "rivalry: high" because it feels competitive → every level needs a named observable (concentration ratio, capex floor, switching cost)
- Static snapshot: structure erodes and reforms — a 2019 analysis applied in 2026 misleads → date the analysis and set reassess triggers
- Boundary games: defining the industry to get the answer you want ("we're not in advertising, we're in attention") → state the boundary explicitly and test the closest alternative boundary

## Evidence Strength
Mixed — one of the most taught strategy frameworks; the industry-structure-profitability link has empirical support at industry level, but critics show it defines away cooperation and innovation responses, and firm-level application often degrades into a checklist.

## Source
Michael Porter, *Competitive Strategy* (1980).
