# SWOT Analysis

## Core Concept
4-quadrant assessment: internal Strengths/Weaknesses × external Opportunities/Threats. A comprehensive but simple framework for situation assessment and strategic direction.

## Applicable Scenarios
✅ **Best for**
- Annual planning
- Product launch assessment
- Strategic transformation

⚠️ **When NOT to use**
- Fast-moving environments — a SWOT is a static snapshot that dates within months; date it and set a refresh trigger
- Industry-structure questions — SWOT describes one player at a time and hides relative position; use **Porter's Five Forces** for industry attractiveness or **PESTLE** for macro context
- Strategy derivation from the matrix alone — S-O/W-O/S-T/W-T pairings are generative prompts, not strategy; they need capability and feasibility assessment behind them
- Unprioritized inputs — 8 bullets per quadrant with no evidence is wall art, not analysis

## Key Steps
1. Define the analysis target (product/company/market)
2. List internal Strengths (what we do well, unique resources)
3. List internal Weaknesses (what we lack, competitive disadvantages)
4. List external Opportunities (market trends, unmet needs)
5. List external Threats (competitors, regulations, market shifts)
6. Generate strategies: S-O (leverage strengths for opportunities), W-O (fix weaknesses to capture opportunities), S-T (use strengths against threats), W-T (minimize weaknesses to avoid threats)

## Output Template

```
Target: [product/company/market]  Date: [date]  Refresh trigger: [event]
Strengths (top 2): [1. item + evidence] [2. item + evidence]
Weaknesses (top 2): [1. item + evidence] [2. item + evidence]
Opportunities (top 2): [1. item + evidence] [2. item + evidence]
Threats (top 2): [1. item + evidence] [2. item + evidence]
Strategy pairings:
  S-O: [leverage strength 1 → capture opportunity 1]
  W-O: [fix weakness 1 → unlock opportunity 2]
  S-T: [use strength 2 → blunt threat 1]
  W-T: [minimize weakness 2 → avoid threat 2]
Owners: [each pairing gets a name + next step]
```

## Failure Modes
- Wall-art lists: 8 items per quadrant with no ranking → force top-2 per quadrant, each backed by named evidence; if the room can't agree on the top 2, the analysis isn't done
- No-evidence brainstorm: strengths and opportunities asserted from optimism → every entry cites a data source or observable fact; the rest are hypotheses, labeled as such
- Pairing theater: S-O/S-T combos generated but never resourced → each pairing leaves the room with an owner and a next step, or it's decoration
- Static snapshot: last year's offsite SWOT still steering this year's bets → date the analysis, define the refresh trigger, treat it as a living planning input

## Evidence Strength
Practitioner consensus — universally taught and genuinely useful as a first-pass situational frame, but weak on prioritization (no built-in ranking mechanism), prone to producing static snapshots that date quickly, and structurally a list generator rather than a decision generator — its value depends entirely on the evidence discipline and follow-through applied after the quadrants are filled.

## Source
Albert Humphrey (1960s); Stanford Research Institute.
