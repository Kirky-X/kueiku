# Product Strategy Canvas

## Core Concept
9-block strategy canvas: Vision, Segments, Value Prop, Trade-offs, Can't-Won't Defensibility, Capabilities, Metrics, Goals, Resources.

## Applicable Scenarios
✅ **Best for**
- Strategy visualization, creating a challengeable 1-page strategy document

⚠️ **When NOT to use**
- You need analysis, not synthesis — the canvas organizes decisions already made; feed it with SWOT / Five Forces / VRIO outputs
- Team has no mandate over the blocks (Resources, Goals set elsewhere) — half-filled canvases create false confidence
- Pivot exploration with many candidate directions — one canvas per direction gets expensive; shortlist first

## Key Steps
1. Fill each of the 9 blocks
2. Ensure internal consistency
3. Validate: can you articulate the strategy in one sentence?
4. Challenge: would a competitor copy this? Why not?

## Output Template

```
Vision       | [where we're going, one sentence]
Segments     | [who we serve first — ranked, not a list of everyone]
Value Prop   | [what they get that alternatives don't offer]
Trade-offs   | [what we deliberately do NOT do — empty = no strategy yet]
Defensibility| [Can't-Won't: why this survives a competent copyist]
Capabilities | [what we must be excellent at, max 3]
Metrics      | [the 2-3 that define winning]
Goals        | [time-bound targets for those metrics]
Resources    | [people/budget assigned — must square with Goals]

One-sentence strategy: [Segments] win via [Value Prop], accepting [Trade-offs], measured by [Metrics], defended by [Defensibility].
Challenge log: [copy question → answer], [consistency conflicts found → resolved how]
```

## Failure Modes
- Trade-offs block left empty or written as "focus" without naming what's forgone → strategy without trade-offs is a wish list; force 2+ explicit "we will not" items
- Blocks filled independently and never reconciled: Goals exceed Resources, Metrics don't track the Value Prop → run the one-sentence test; contradiction shows up immediately
- Canvas worship: a filled canvas treated as a finished strategy — it's a map of hypotheses → attach the riskiest assumption and its test

## Evidence Strength
Practitioner consensus — a synthesis scaffold aggregating better-validated parts (JTBD value props, Can't-Won't defensibility, goal metrics); the canvas itself claims no predictive power, only coherence.
