# McKinsey 7S

## Core Concept
7-dimension organizational diagnosis: Strategy, Structure, Systems, Staff, Skills, Style, Shared Values.

## Applicable Scenarios
✅ **Best for**
- Organizational capability assessment, internal consistency check, change resistance analysis

⚠️ **When NOT to use**
- Diagnosing a single team's dysfunction — the framework is organization-scale; team issues need narrower tools
- Rapid triage — honest assessment of 7 dimensions takes interviews across levels, not a workshop afternoon
- You lack access to the organization's informal reality (systems described on paper vs as practiced diverge)

## Key Steps
1. Assess each of the 7 dimensions
2. Identify misalignments between dimensions
3. Prioritize changes: start with Shared Values (the center)
4. Design change plan addressing misalignments
5. Monitor: do changes in one S cascade to others?

## Output Template

```
| S             | Current state (evidence, not adjectives)      | Aligned with strategy? | Misaligned with |
| ------------- | --------------------------------------------- | ---------------------- | --------------- |
| Strategy      | [one line + source]                           | —                      | [S1, S2]        |
| Structure     | [org shape, decision rights]                  | [yes/no/partial]       | [Systems]       |
| Systems       | [planning, comp, info flows as practiced]     | [yes/no/partial]       | [Incentives reward X while strategy needs Y] |
| Staff         | [composition, gaps]                           | ...                    | ...             |
| Skills        | [distinctive capabilities, missing ones]      | ...                    | ...             |
| Style         | [how leaders actually spend time/signals]     | ...                    | ...             |
| Shared Values | [stated vs lived — with examples]             | ...                    | ...             |

Top misalignments (ranked): 1. [A↔B because ...] 2. [...]
Change entry point: [Shared Values / one hard S] — why starting there: [cascade argument]
```

## Failure Modes
- Adjective soup: "strong culture, good systems" — uncheckable → every cell needs one piece of evidence (artifact, metric, quote)
- Hard-S bias: only Structure/Systems get assessed because they're visible → the soft S's are where misalignment usually hides
- Change plan ignores cascades: fixing Structure breaks Systems it was aligned with → after each planned change, re-scan adjacent S's

## Evidence Strength
Practitioner consensus — the dominant value is forcing simultaneous attention to soft and hard elements (most alternatives over-index on structure); there is no rigorous validation of the specific 7-way split, and firms rarely have data to score the soft S's well.

## Source
Tom Peters & Robert Waterman, *In Search of Excellence* (1982); McKinsey & Company.
