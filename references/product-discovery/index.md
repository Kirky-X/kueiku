# Product Discovery

**Use Cases**: Continuous product discovery, hypothesis validation, user interviews, experiment design

| Method | One-Line Description | Best For | Reference |
| --- | --- | --- | --- |
| **Opportunity Solution Tree** | Outcome→Opportunities→Solutions→Experiments 4-layer structure | Continuous discovery, aligning discovery with business outcomes | `opportunity-solution-tree.md` |
| **Assumption Mapping** | 4/8 risk categories × Impact×Risk matrix | Pre-project identification of "what are we betting on" | `assumption-mapping.md` |
| **Pretotypes** | XYZ hypothesis + lightweight pretotype + Skin-in-the-Game | Validate demand existence before writing code | `pretotypes.md` |
| **The Mom Test** | Ask about the past not the future, don't pitch, 80/20 listening | User interviews avoiding false positive feedback | `mom-test.md` |
| **Product Trio** | PM+Designer+Engineer collaborative discovery | Discovery work no longer carried by PM alone | `product-trio.md` |
| **Opportunity Score** | Importance × (1−Satisfaction) normalized 0-1 | Find unmet needs, identify product opportunities | `opportunity-score.md` |
| **ICE Framework** | Impact×Confidence×Ease, lightweight RICE alternative | Quick screening of many ideas within 30 minutes | `ice-framework.md` |
| **Experiment Design Library** | 7 experiment types as a selectable menu | Hypothesis validation experiment selection | `experiment-design-library.md` |

## Minimum Information Requirements Per Method

- **Opportunity Solution Tree**: Requires a clear business Outcome + user interview data
- **Assumption Mapping**: Requires a clear plan/solution + ability to enumerate dependent assumptions
- **Pretotypes**: Requires articulable XYZ hypotheses + execution capability for the chosen pretotype type
- **The Mom Test**: Requires accessible target users + interview opportunities
- **Product Trio**: Requires PM/Designer/Engineer all able to commit to weekly interviews
- **Opportunity Score**: Requires reachable target users for importance + satisfaction surveys
- **ICE Framework**: Requires a candidate idea list + 30-minute team discussion
- **Experiment Design Library**: Requires a clear hypothesis to validate

## Routing Trigger Signals

- "Continuous product discovery / align discovery with business outcomes" → Opportunity Solution Tree (primary)
- "User interviews avoiding false positive feedback" → The Mom Test (primary)
- "Quick early-stage idea screening (<30 min)" → ICE Framework (primary)
- "Find unmet needs / identify product opportunities" → Opportunity Score (primary)
- "Hypothesis validation experiment selection" → Experiment Design Library (primary)
- "Assumption identification and classification" / "Uncertainty mapping" → Assumption Mapping
- "Minimum viable prototype" / "pretotype" → Pretotypes
- "Product team collaboration" / "trio roles" → Product Trio
