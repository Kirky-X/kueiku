# Industry Analysis

**Applicable Scenario**: When you need to understand industry structure, value distribution, and technology maturity for entry/investment decisions.

| Methodology | One-line Description | Best Scenario | Reference |
|-------------|----------------------|---------------|-----------|
| **Industry Value Chain** | Full-chain value distribution from raw materials to end-users, identifying profit pools and shift trends | Industry entry decisions, value chain positioning, M&A target screening | `industry-value-chain.md` |
| **Gartner Hype Cycle** | 5-stage model from trigger to maturity for technologies, determining adoption timing | Technology investment timing, new technology adoption decisions, technology roadmaps | `gartner-hype-cycle.md` |

## Minimum Information Requirements for Each Methodology

- **Industry Value Chain**: List of industry chain segments + financial/profit data for each segment
- **Gartner Hype Cycle**: Target technology name + Gartner annual report or equivalent maturity assessment

## Routing Trigger Signals

- "Industry value distribution/profit pools/value chain positioning/M&A targets" → Industry Value Chain (primary)
- "Technology maturity/new technology adoption timing/technology roadmap" → Gartner Hype Cycle (primary)
- "Entering new industries/industry structure analysis" → Industry Value Chain (primary)

## Common Combinations

- **Industry entry decision**: Systematic Research Process (information collection) → Industry Value Chain (value distribution) → Porter's Five Forces (competitive landscape) → Gartner Hype Cycle (technology timing)
- **Technology investment decision**: Gartner Hype Cycle (maturity) → Industry Value Chain (value chain positioning) → DCF (input-output)
- **M&A target screening**: Industry Value Chain (identify value shift direction) → Comparable Company (valuation) → DuPont Analysis (financial quality)
