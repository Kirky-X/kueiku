# Industry Analysis

**When to use**: Need to understand industry structure, value distribution, technology maturity for entry/investment decisions

| Methodology | One-line description | Best scenario | Reference |
| --- | --- | --- | --- |
| **Industry Value Chain** | Full-chain value distribution from raw materials to end users, identifying profit pools and shift trends | Industry entry decisions, value chain positioning, M&A target screening | `industry-value-chain.md` |
| **Gartner Hype Cycle** | 5-stage model from trigger to maturity, timing adoption | Technology investment timing, new technology adoption decisions, technology roadmaps | `gartner-hype-cycle.md` |

## Minimum Information Requirements per Methodology

- **Industry Value Chain**: Industry chain stage list + financial/profit data per stage
- **Gartner Hype Cycle**: Target technology name + Gartner current year report or equivalent maturity assessment

## Routing Trigger Signals

- "Industry value distribution / profit pool / value chain positioning / M&A target" → Industry Value Chain (primary)
- "Technology maturity / new technology adoption timing / technology roadmap" → Gartner Hype Cycle (primary)
- "Entering new industry / industry structure analysis" → Industry Value Chain (primary)

## Common Combinations

- **Industry entry decision**: Systematic Research Process (information gathering) → Industry Value Chain (value distribution) → Porter's Five Forces (competitive landscape) → Gartner Hype Cycle (technology timing)
- **Technology investment decision**: Gartner Hype Cycle (maturity) → Industry Value Chain (value chain positioning) → DCF (ROI assessment)
- **M&A target screening**: Industry Value Chain (identify value shift direction) → Comparable Company (valuation) → DuPont Analysis (financial quality)
