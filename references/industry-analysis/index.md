# Industry Analysis · 行业分析

**适用场景**：需要理解行业结构、价值分布、技术成熟度以做进入/投资决策

| 方法论 | 一句话描述 | 最佳场景 | Reference |
| --- | --- | --- | --- |
| **Industry Value Chain** | 从原材料到终端用户的全链路价值分布，识别利润池和转移趋势 | 行业进入决策、价值链定位、并购目标筛选 | `industry-value-chain.md` |
| **Gartner Hype Cycle** | 技术从触发到成熟的 5 阶段模型，判断采用时机 | 技术投资时机、新技术采用决策、技术路线图 | `gartner-hype-cycle.md` |

## 各方法论最低信息需求

- **Industry Value Chain**：行业链路环节清单 + 各环节财务/利润数据
- **Gartner Hype Cycle**：目标技术名称 + Gartner 当年报告或等效成熟度评估

## 路由触发信号

- "行业价值分布/利润池/价值链定位/并购目标" → Industry Value Chain（主）
- "技术成熟度/新技术采用时机/技术路线图" → Gartner Hype Cycle（主）
- "进入新行业/行业结构分析" → Industry Value Chain（主）

## 常见组合

- **行业进入决策**：Systematic Research Process（信息收集）→ Industry Value Chain（价值分布）→ Porter's Five Forces（竞争格局）→ Gartner Hype Cycle（技术时机）
- **技术投资决策**：Gartner Hype Cycle（成熟度）→ Industry Value Chain（价值链定位）→ DCF（投入产出）
- **并购目标筛选**：Industry Value Chain（识别价值转移方向）→ Comparable Company（估值）→ DuPont Analysis（财务质量）
