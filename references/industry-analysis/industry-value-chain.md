# Industry Value Chain

## Core Concept
Map the full chain from raw materials to end users, identifying value creation and profit distribution at each stage. Reveals profit pools, shift trends, and strategic positioning opportunities.

## Applicable Scenarios
✅ **Best for**
- Industry entry decisions
- Value chain positioning
- M&A target screening

## Key Steps
1. Map the industry value chain stages (raw materials → manufacturing → distribution → retail → end user)
2. For each stage, estimate: revenue pool, profit margin, growth rate
3. Identify profit pool shifts: where are margins migrating?
4. Assess your current position and potential entry points
5. Evaluate competitive dynamics at each stage
6. Make positioning decision based on profit pool trends

## Source
Michael Porter, *Competitive Advantage* (1985); value chain analysis framework.
