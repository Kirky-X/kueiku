# GTM Strategy

## Core Concept
Phased go-to-market plan covering: channel selection, messaging framework, success metrics, and launch phases. Translates product strategy into executable market entry.

## Applicable Scenarios
✅ **Best for**
- Launch planning
- Market entry execution
- Cross-functional GTM alignment

⚠️ **When NOT to use**
- Beachhead segment or ICP not yet chosen — the plan would inherit fiction; resolve those first
- A single-channel experiment or side project — full phased-launch machinery outweighs the decision; run the experiment instead
- Messaging when no customer language exists yet — draft messaging from interviews, not internal workshops

## Key Steps
1. Define target segment and ICP
2. Select GTM motions (see GTM Motions)
3. Craft messaging framework: problem → solution → differentiation → proof
4. Define success metrics per phase
5. Plan phased launch: soft launch → general availability → expansion
6. Align cross-functional teams (product, marketing, sales, support)

## Output Template

```
Segment / ICP: [...]  Motion: [primary + backup]

Messaging: problem=[...] solution=[...] differentiation=[...] proof=[...]
Phases:
  Soft launch   — scope=[...] metric=[...] exit criterion=[...]
  GA            — scope=[...] metric=[...] exit criterion=[...]
  Expansion     — scope=[...] metric=[...]
Cross-functional RACI: [product / marketing / sales / support]
Kill/pivot criteria: [what stops this plan]
```

## Failure Modes
- Phase theater: phases without exit criteria — GA happens because the calendar said so → every phase names its metric and exit criterion up front
- Messaging by committee: internally polished, customer-untested → validate messaging with 5 target-customer conversations before GA
- Success metrics nobody owns: launch metrics without a named owner per phase → each metric gets one owner and a review date

## Evidence Strength
Practitioner consensus (phased launch, messaging frameworks are standard practice); the specific phase structure is convention and varies by motion. No controlled evidence ranks messaging frameworks — instrument the funnel instead of debating frameworks.

## Source
Standard GTM methodology; combining multiple GTM frameworks.
