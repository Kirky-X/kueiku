# Growth Loops

## Core Concept
5 types of sustainable growth loops: Viral (users invite users), Usage (more usage → more value → more usage), Collaboration (working together creates network effects), UGC (user-generated content attracts more users), Referral (explicit referral programs). Unlike funnels, loops compound.

## Applicable Scenarios
✅ **Best for**
- Sustainable growth mechanism design
- Moving beyond paid acquisition dependency
- Product-led growth strategies

## Key Steps
1. Map current acquisition channels (funnel view)
2. Identify potential loop types for your product
3. For each loop, define: Input → Activity → Output → Re-input
4. Quantify the loop coefficient (K-factor): how many new users per existing user per cycle?
5. Prioritize loops with K > 1 or highest potential
6. Design experiments to test and optimize each loop
