# Growth Loops

## Core Idea
The traditional funnel model (AARRR) is linear — inputs produce outputs, and outputs don't feed back into inputs. Growth Loops emphasize that sustainable growth must form a closed loop: the product's output becomes the next cycle's input, enabling growth without continuously increasing investment. Identifying and proactively designing loops matters more than stacking acquisition channels.

## Applicable Scenarios
- CAC keeps rising, funnel-based growth hits a ceiling
- Need to find a "one-time investment, continuous return" growth mechanism
- Evaluating which growth channels are sustainable and which are burning cash

## Key Steps
1. Identify 5 candidate loop types:
   - Viral: Users bring in new users through product usage (e.g., Zoom invitations)
   - Usage: More usage increases value, attracting more usage (e.g., Slack workflows)
   - Collaboration: Multi-user collaborative products naturally expand (e.g., Figma/Notion)
   - User-Generated Content: Users create content that attracts new users (e.g., Reddit/YouTube)
   - Referral: Explicit referral mechanisms (e.g., Dropbox two-sided rewards)
2. Quantify key coefficients for each loop: input → action → output → new input conversion rates and amplification factors
3. Select 1 primary loop and concentrate investment to avoid resource dilution
4. Calculate the loop's "compound growth rate" — below 1 means it's decaying
5. Monitor whether the loop is disrupted by external factors (e.g., platform policy changes)

## Source
Sean Ellis & Morgan Brown, *Hacking Growth* (2017); loop concept popularized by Reforge
