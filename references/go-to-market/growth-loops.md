# Growth Loops

## Core Concept
5 types of sustainable growth loops: Viral (users invite users), Usage (more usage → more value → more usage), Collaboration (working together creates network effects), UGC (user-generated content attracts more users), Referral (explicit referral programs). Unlike funnels, loops compound.

## Applicable Scenarios
✅ **Best for**
- Sustainable growth mechanism design
- Moving beyond paid acquisition dependency
- Product-led growth strategies

⚠️ **When NOT to use**
- Pre-product-market-fit — loops compound retention problems too; validate PMF first
- The product's value is not measurable in-product (offline services, invisible outcomes) — K-factor cannot be quantified; use funnel analysis instead
- One-shot or infrequent-usage products with no repeat cycle to close a loop

## Key Steps
1. Map current acquisition channels (funnel view)
2. Identify potential loop types for your product
3. For each loop, define: Input → Activity → Output → Re-input
4. Quantify the loop coefficient (K-factor): how many new users per existing user per cycle?
5. Prioritize by measured K × cycle speed × testability — K > 1 is the exponential bar for a pure viral loop, not the admission bar for a loop: a compounding loop with K < 1 can still beat a linear funnel
6. Design experiments to test and optimize each loop

## Output Template

```
Current acquisition (funnel view): [channels + CAC + volume]

Candidate loops:
  [Loop type]  Input → Activity → Output → Re-input
               K estimate=[x]  time-to-cycle=[...]  confidence=[H/M/L]

Priority: [loop] — why: [highest K × fastest cycle × most testable]
First experiment: [hypothesis + instrument + decision rule]
```

## Failure Modes
- Loop wishlist: five loops "designed", none instrumented → one loop instrumented beats five diagrammed; K must be measured, not estimated, before prioritization
- Ignoring loop decay: K measured at launch, assumed forever → re-measure per cycle; loops saturate as invitation pools exhaust
- Forced virality: looping mechanics that degrade the core experience → the loop's Activity must be the product's natural use, not a bolt-on ask

## Evidence Strength
Practitioner consensus that compounding loops outperform linear funnels for products with in-product value and repeat usage; loop taxonomy is descriptive, and published K-factor benchmarks are survivor-biased. The funnel-vs-loop framing is well argued but not experimentally isolated.

## Source
Sarah Tavel, *The Hierarchy of Engagement* (2017); the loops-vs-funnels framing was popularized by Brian Balfour / Reforge (2018) and Gagan Biyani, *Why You Should Be Focusing on Growth Loops, Not Funnels* (2019); Elena Verna's Reforge work on loop design.
