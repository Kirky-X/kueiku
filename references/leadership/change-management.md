# Change Management · 变革管理

## 核心理念

组织变革 70% 失败，多数不是因为战略错误，而是因为执行中的人的抵抗。变革管理提供从"当前状态"到"目标状态"的人的系统化过渡方法。

> "人们不会抵制变革，他们抵制的是被改变。" —— Russell Ackoff

## 适用场景

✅ **最适合**
- 组织级变革（并购整合、文化转型、数字化转型）
- 需要大规模行为改变（流程切换、工具迁移）
- 利益相关方阻力大的战略调整
- 变革已宣布但推进困难

⚠️ **慎用**
- 纯技术变更（无组织影响，用 Bite-Sized Plan 即可）
- 日常运营优化（用 OKR + Lean BML 即可）
- 团队 < 5 人的小团队（直接沟通即可，无需正式框架）

## 执行步骤

### 模型 A：Kotter 8 步法（组织级变革）

#### Step 1：建立紧迫感

让组织感受到"不变不行"的危机。

```
关键动作：
  识别并展示危机信号（市场数据、竞争威胁、客户流失）
  创造"burning platform"——不变的成本 > 变革的成本
  避免虚假紧迫感（真正的危机 vs 制造的焦虑）

检验标准：
  75% 以上管理层认为"维持现状不可接受"
```

#### Step 2：组建指导联盟

聚集足够权力和影响力的人推动变革。

```
关键动作：
  识别关键决策者和影响者（搭配 Stakeholder Mapping）
  建立跨职能指导团队（非单一部门推动）
  建立信任和共同目标

团队构成：
  核心层：3-5 位高管级 sponsor
  执行层：各部门变革 champion
  支持层：HR / 沟通 / 培训资源
```

#### Step 3：制定愿景与战略

清晰定义"我们要去哪里"和"为什么"。

```
愿景检验（5 分钟测试）：
  能否在 5 分钟内说清楚？
  听者能否复述核心要点？
  是否包含具体可衡量的目标状态？
```

#### Step 4：沟通变革愿景

通过多渠道反复沟通，确保组织理解并认同。

```
沟通原则：
  频率：至少 10x 你认为足够的次数
  渠道：全员会 + 小组讨论 + 1:1 + 书面（搭配 Stakeholder Mapping 选渠道）
  双向：留出提问和反馈空间
  一致性：所有领导层口径一致
```

#### Step 5：授权行动

消除障碍，让员工能够执行新愿景。

```
障碍类型及对策：
  结构障碍 → 调整组织架构、汇报关系
  技能障碍 → 培训、辅导、轮岗
  制度障碍 → 修改 KPI、流程、审批
  心理障碍 → 1:1 沟通、教练、示范效应
```

#### Step 6：创造短期胜利

制造可见的、快速的成功，维持变革动力。

```
短期胜利设计原则：
  可见性：全组织能看到
  明确性：与变革直接相关（非巧合）
  意义性：对参与者有实际价值
  时间性：6-18 个月内可见
```

#### Step 7：巩固并推进

利用短期胜利的信誉，推动更深层变革。

```
关键动作：
  公开认可并奖励参与者
  利用信誉解决更大的系统性问题
  持续引入新变革 champion
  警惕"宣布胜利就停"——这是最常见的失败点
```

#### Step 8：固化到文化

将变革成果嵌入制度、流程和文化。

```
固化机制：
  调整绩效考核和晋升标准
  更新培训体系（新人入职即接受新文化）
  确保领导层持续示范新行为
  建立反馈机制防止回退
```

### 模型 B：ADKAR 模型（个人级转变）

个人转变的 5 个阶段，每个阶段必须按顺序达成：

```
A - Awareness（认知）  → 理解为什么需要变革
D - Desire（意愿）     → 愿意参与和支持变革
K - Knowledge（知识）  → 知道如何变革
A - Ability（能力）    → 能够执行新行为
R - Reinforcement（强化） → 确保变革持续

诊断方法：
  对每个受影响的人/群体，评估 ADKAR 各阶段 1-5 分
  找到最低分阶段——那就是瓶颈
  不要跳过瓶颈进入下一阶段
```

## 常见陷阱

| 陷阱 | 避免方式 |
|------|---------|
| 跳过紧迫感直接推方案 | 先花 2-4 周建立紧迫感（Step 1） |
| 指导联盟权力不足 | 确保有足够高管级 sponsor |
| 缺少短期胜利 | 在计划阶段就设计短期胜利 |
| 宣布胜利就停 | 用 Step 7 持续推进直到文化固化 |
| 只关注组织级忽视个人转变 | 搭配 ADKAR 诊断个人瓶颈 |
| 沟通不足 | 沟通频率 ≥ 你认为需要的 10 倍 |

## 与其他方法论的关系

- **搭配 Stakeholder Mapping**：识别变革中的关键利益相关方及其影响力×利益
- **搭配 McKinsey 7S**：诊断组织当前一致性，识别变革需要调整的维度
- **搭配 OKR**：将变革目标拆解为可追踪的关键结果
- **搭配 Six Thinking Hats**：在变革讨论中引导多视角思考，减少抵抗
- **搭配 A-Player Density**：确保变革团队有足够的人才密度
