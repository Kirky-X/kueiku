# Structured Thinking · Structured Thinking

**Applicable Scenarios**: Organizing complex information, enhancing analytical rigor, clear expression, clarifying assumptions

| Methodology | One-line Description | Best Scenario | Reference |
| --- | --- | --- | --- |
| **MECE + Pyramid Principle** | Mutually exclusive, collectively exhaustive structured thinking + conclusion-first expression | Consulting reports, complex problem decomposition, upward reporting | `mece-pyramid.md` |
| **Six Thinking Hats** | Six thinking modes with forced switching, aligning the team on the same perspective simultaneously | Team reviews, comprehensive evaluation of proposals, breaking discussion deadlocks | `six-thinking-hats.md` |
| **Socratic Questioning** | Systematic questioning to clarify assumptions, test logic, and expose contradictions | Ambiguous problem definition, strategies relying on unverified assumptions, requirement clarification | `socratic-questioning.md` |
| **Cynefin Framework** | Classifies problem domains into clear/complicated/complex/chaotic categories, matching different response strategies | Determining problem nature, pre-selecting methodology, complex/uncertain situations | `cynefin.md` |
| **Second-Order Thinking** | Asks "and then what?", analyzing second-order and third-order chain effects of decisions | Policy decisions, pricing changes, ecosystem effect analysis | `second-order-thinking.md` |
| **Framework Selection** | Meta-methodology with 5 principles + decision tree for framework selection | Meta-decisions when choosing frameworks, preventing framework misuse, team framework alignment | `framework-selection.md` |
| **Connecting Dots** | Cross-domain knowledge connections to spark innovation | Innovation brainstorming, cross-boundary thinking, personal growth planning | `connecting-dots.md` |
| **Reframe and Elevate** | Reframe the problem + elevate abstraction level to find new perspectives | Problem roadblocks, innovation breakthroughs, strategic repositioning, dilemma decisions | `reframe-and-elevate.md` |

## Minimum Information Requirements for Each Methodology

- **MECE + Pyramid Principle**: A clearly defined complex problem to express/decompose (conclusion-first + mutually exclusive, collectively exhaustive)
- **Six Thinking Hats**: A clear topic/problem statement
- **Socratic Questioning**: A specific claim or assumption as a starting point
- **Cynefin**: A problem description (for determining the problem domain)
- **Second-Order Thinking**: A clear decision/action plan
- **Framework Selection**: A clear problem statement + list of candidate frameworks
- **Connecting Dots**: Cross-domain knowledge reserves + a clear problem
- **Reframe and Elevate**: Current problem framework + roadblock point

## Routing Trigger Signals

- "Structured expression/analysis framework" → MECE + Pyramid Principle (primary)
- "Multi-perspective comprehensive evaluation/team discussion" → Six Thinking Hats (primary)
- "Clarify ambiguous assumptions/question premises" → Socratic Questioning (primary)
- "Complex problem domain assessment/strategy selection" → Cynefin Framework (primary)
- "Decision chain effects/second-order consequence analysis" → Second-Order Thinking (primary)
- "Which framework to choose/framework misuse/meta-decision" → Framework Selection (primary)
- "Innovation brainstorming/cross-boundary thinking/connecting dots" → Connecting Dots (primary)
- "Problem roadblock/reframe problem/think at higher level" → Reframe and Elevate (primary)

## Common Combinations

- **Major Decisions**: Socratic Questioning (clarify assumptions) → Decision Matrix → Pre-mortem (risk review)
- **Systematic Creativity**: Six Thinking Hats (green hat) → SCAMPER → RICE (filtering)
- **Organizational Change**: Stakeholder Mapping → Six Thinking Hats → OKR
- **Comprehensive Risk Assessment**: FMEA → Pre-mortem → Second-Order Thinking
- **Growth Strategy Development**: Cynefin (determine problem domain) → Ansoff Matrix → Blue Ocean
- **Framework Selection and Reframing**: Framework Selection (choose framework) → If no framework works → Reframe and Elevate (reframe the problem)
- **Innovation Breakthrough**: Reframe and Elevate (reframe perspective) → Connecting Dots (cross-domain connections) → Six Thinking Hats (green hat divergence)
