# Portfolio Optimization · 投资组合优化

## 核心理念

在给定风险水平下最大化预期收益，或在给定收益目标下最小化风险。

Markowitz 均值-方差优化（MVO）是现代投资组合理论的基石：通过资产间的低相关性实现分散化，构建有效前沿。Black-Litterman 模型则解决了 MVO 对预期收益估计过度敏感的问题，将市场均衡观点与投资者主观看法用贝叶斯方法融合。

> **核心理念**：分散化是唯一的"免费午餐"。
> 但优化器只对输入负责——垃圾输入产生极端集中持仓。稳健的协方差估计和合理的约束条件比优化算法本身更重要。

---

## 适用场景

✅ **最适合**
- 多资产组合的权重分配
- 风险预算与分散化管理
- 将主观观点量化为组合调整
- 长期战略资产配置（SAA）

⚠️ **慎用**
- 资产数量远多于样本数（需降维或收缩估计）
- 极端市场环境（相关性趋同，分散化失效）
- 非正态收益分布（厚尾风险需额外处理）
- 高换手约束场景（优化结果可能引发大量调仓）

## 执行步骤

### Step 1：估计预期收益与协方差矩阵

MVO 的核心输入是预期收益向量 μ 和协方差矩阵 Σ：

```
预期收益估计方法：
  - 历史均值：简单但有噪声，需长窗口
  - 收缩估计：Ledoit-Wolf 收缩到常数相关/单因子结构
  - 隐含均衡收益（Black-Litterman 用）：从市值权重反推

协方差矩阵估计方法：
  - 样本协方差：直接计算，但高维不稳定
  - Ledoit-Wolf 收缩：向结构化目标收缩，稳健
  - 指数加权移动平均（EWMA）：近期数据更高权重
  - DCC-GARCH：动态条件相关，捕捉时变相关性
  - 随机矩阵理论（RMT）：去噪特征值

  关键原则：协方差矩阵必须是正定矩阵，否则优化无解
```

### Step 2：Markowitz 均值-方差优化

构建有效前沿和最优组合：

```
优化问题：
  max  w'μ - (λ/2) w'Σw
  s.t. Σwᵢ = 1（完全投资）
       wᵢ ≥ 0（禁止做空，可选）
       wᵢ ≤ w_max（个股权重上限，可选）
       其他约束（行业/资产类别/换手率）

  λ = 风险厌恶系数，通常 2-4

有效前沿：
  在不同目标收益下求解最小方差，得到有效前沿曲线
  切线组合 = 夏普比率最高的组合

关键输出：
  - 最优权重 w*
  - 预期收益 E(Rp) = w'μ
  - 组合波动率 σp = √(w'Σw)
  - 夏普比率 SR = (E(Rp) - Rf) / σp
```

### Step 3：Black-Litterman 模型

将市场均衡与投资者观点融合：

```
Step 3a：计算隐含均衡收益
  Π = (δΣ)w_mkt
  Π：隐含均衡收益向量
  δ：市场风险厌恶系数（通常 2-3.5）
  w_mkt：市场组合权重（市值加权）

Step 3b：编码投资者观点
  每个观点表示为：Pᵢw = Qᵢ ± εᵢ
  P：观点矩阵（每行一个观点，列对应资产）
  Q：观点预期收益向量
  Ω：观点不确定性矩阵（对角阵）

  观点示例：
  - "A 资产下月涨 5%"：P=[1,0,...], Q=0.05
  - "A 比 B 多涨 2%"：P=[1,-1,0,...], Q=0.02

Step 3c：贝叶斯后验
  μ_BL = [(τΣ)⁻¹ + P'Ω⁻¹P]⁻¹ [(τΣ)⁻¹Π + P'Ω⁻¹Q]
  Σ_BL = Σ + [(τΣ)⁻¹ + P'Ω⁻¹P]⁻¹

  τ：缩放参数（通常 0.05-0.1），控制均衡收益的不确定性
  μ_BL：后验预期收益（融合观点与均衡）
  Σ_BL：后验协方差（略大于 Σ）

Step 3d：用 μ_BL 和 Σ 做 MVO
```

> Black-Litterman 的核心价值：不表达观点时，退化为市场组合；表达观点时，调整幅度与观点置信度成正比。避免 MVO 的极端持仓。

### Step 4：施加实际约束

真实世界的约束条件：

```
常见约束集：
  权重约束：0 ≤ wᵢ ≤ 5%（个股上限）
  行业约束：|w_sector - b_sector| ≤ 5%（行业偏离限制）
  换手约束：|wᵢ - wᵢ_prev| ≤ Δ（控制调仓成本）
  最低持仓：wᵢ ≥ 0（禁止做空）或 wᵢ ∈ {0} ∪ [min, max]
  跟踪误差：TE(w) ≤ 目标 TE（相对基准的主动风险）
  流动性约束：wᵢ × AUM ≤ 日均成交额 × X%

约束后优化 = 二次规划（QP），用 cvxpy / scipy.optimize 求解
```

### Step 5：稳健性检验

验证优化结果对输入的敏感性：

```
稳健性检验清单：
  - 收益敏感性：μ ± 10% 对权重的影响
  - 协方差敏感性：不同估计方法（样本/收缩/EWMA）的权重差异
  - 重采样：Bootstrap 抽样 1000 次，看权重分布
  - 有效前沿稳定性：不同窗口的有效前沿是否一致
  - 约束影响：放松/收紧约束对夏普比率的影响

  如果权重对输入微小变化极度敏感 → 模型不稳定，需加强约束或使用 Black-Litterman
```

## 常见陷阱

| 陷阱 | 避免方式 |
|------|---------|
| MVO 对预期收益极度敏感 | 用 Black-Litterman 或等权/最小方差替代 |
| 协方差矩阵估计不稳定 | 用收缩估计或 EWMA，不直接用样本协方差 |
| 极端集中持仓 | 施加上限约束，或使用风险平价/最小方差 |
| 忽略交易成本 | 加入换手约束，评估净收益（扣成本后） |
| 历史收益不代表未来 | 用多情景分析，不只依赖历史均值 |
| 优化器过拟合 | 稳健性检验 + 简化资产数量（先聚类再分配） |
| 正定性问题 | 协方差矩阵需检验正定性，必要时修正 |

## 与其他方法论的关系

- **前置 Factor Investing**：因子信号可作为预期收益的输入来源
- **互补 Risk Parity**：Risk Parity 是 MVO 的特例（特定风险厌恶系数下的解）
- **后接 Backtesting Framework**：优化结果需回测验证样本外表现
- **互补 DCF**：DCF 估值可提供个股预期收益估计，作为 MVO 输入
- **搭配 Momentum Strategy**：动量信号可融入 Black-Litterman 的观点矩阵
