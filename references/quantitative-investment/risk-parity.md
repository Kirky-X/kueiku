# Risk Parity · 风险平价

## 核心理念

按风险贡献均等分配权重，让每个资产/策略对组合总风险的贡献相等。

传统 60/40 组合中，股票贡献了 90%+ 的风险。风险平价打破资金均配的直觉，转向风险均配——低波动资产（债券）获得更高杠杆权重，高波动资产（股票）权重更低，使各资产的风险贡献均衡。Bridgewater 的 All Weather 基金是其最著名的实践。

> **核心理念**：分配的不是资金，而是风险。
> 60/40 不是"均衡"——它只是把 90% 的赌注押在经济增长上。真正的均衡是让每种宏观环境承担相同的风险。

---

## 适用场景

✅ **最适合**
- 大类资产配置（股票/债券/商品/另类）
- 降低组合对单一风险因子的集中度
- 长期战略配置（不依赖收益预测）
- 风险预算与绩效归因

⚠️ **慎用**
- 利率长期上行环境（债券杠杆部分亏损）
- 无法使用杠杆的账户（低波资产无法加杠杆达到目标收益）
- 资产类别过少（2 个以下资产的风险平价意义有限）
- 需要精确预测收益的场景（风险平价不预测收益）

## 执行步骤

### Step 1：定义资产类别与风险因子

确定参与风险分配的资产/策略：

```
典型资产类别：
  股票：本国/发达市场/新兴市场
  债券：国债/信用债/通胀保护债
  商品：能源/金属/农产品
  另类：REITs/对冲基金/私募

风险因子视角（更底层）：
  经济增长：股票、信用债、商品正相关
  通胀：TIPS、商品、房地产正相关
  流动性：股票、信用债、高收益债正相关
  利率：长债 vs 短债

  原则：资产类别应覆盖不同的宏观风险因子
```

### Step 2：估计风险模型

计算各资产波动率和相关性：

```
波动率估计：
  - 已实现波动率：过去 N 天日收益标准差 × √252
  - EWMA 波动率：近期数据更高权重，响应更快
  - GARCH 波动率：模型化波动率聚集效应

相关性估计：
  - 样本相关矩阵
  - 收缩估计（Ledoit-Wolf）
  - 因子模型隐含相关性

  窗口选择：
  - 短窗口（60-90 天）：响应快但噪声大
  - 长窗口（252-756 天）：稳定但滞后
  - 推荐：混合使用或 EWMA（λ=0.94）
```

### Step 3：计算风险贡献与目标权重

风险平价的核心优化：

```
风险贡献定义：
  组合方差 σ²p = w'Σw
  资产 i 的边际风险贡献：MRCᵢ = (Σw)ᵢ / σp
  资产 i 的风险贡献：RCᵢ = wᵢ × MRCᵢ
  验证：Σ RCᵢ = σp

风险平价优化目标：
  min  Σ(RCᵢ - RC_target)²
  s.t. Σwᵢ = 1
       wᵢ ≥ 0
       RC_target = σp / N（N 为资产数）

  等价形式（两资产简化）：
  w₁/w₂ = σ₂/σ₁（波动率反比加权）

  推广到 N 资产：
  wᵢ ∝ 1/σᵢ（简化版，忽略相关性）
  精确版需迭代求解（考虑相关性矩阵）
```

### Step 4：杠杆调整（如需要）

风险平价组合波动率通常低于目标，需加杠杆：

```
杠杆调整：
  目标组合波动率：σ_target（如 10%）
  风险平价组合波动率：σ_rp
  杠杆倍数：L = σ_target / σ_rp

  杠杆实现方式：
  - 期货：国债期货、股指期货（最常用）
  - 融资：保证金借款
  - 杠杆 ETF

  约束：
  - 总杠杆 ≤ 3x（实操上限）
  - 保证金缓冲：预留追加保证金空间
  - 滚动成本：期货展期收益/损失
```

### Step 5：动态再平衡

定期调整权重以维持风险均衡：

```
再平衡策略：
  定期再平衡：月度/季度
  阈值触发：某资产风险贡献偏离目标 > X%
  混合：月度检查 + 5% 偏离阈值触发调仓

  再平衡时需考虑：
  - 交易成本（期货展期、ETF 买卖）
  - 税收影响
  - 信号衰减（波动率估计的时效性）

  绩效归因：
  - 各资产风险贡献 vs 收益贡献
  - 再平衡收益（rebalancing premium）
  - 杠杆成本拖累
```

## 常见陷阱

| 陷阱 | 避免方式 |
|------|---------|
| 忽略杠杆风险 | 杠杆是 RP 的核心风险源，需设上限和保证金缓冲 |
| 波动率估计窗口不当 | 短窗口追涨杀跌，长窗口反应迟钝，用 EWMA 平衡 |
| 资产类别太少 | 至少 3-4 个低相关资产类别，否则 RP 退化为等权 |
| 利率上行期债券杠杆巨亏 | 监控宏观环境，必要时加入趋势过滤降低债券杠杆 |
| 忽略再平衡成本 | 高成本资产降低再平衡频率，用阈值触发 |
| 把 RP 当"不需要预测"就万事大吉 | RP 不预测收益，但仍需估计波动率和相关性 |
| 相关性稳定假设 | 危机时相关性飙升，需压力测试 |

## 与其他方法论的关系

- **互补 Portfolio Optimization**：RP 是 MVO 的特例，可视为 MVO 框架下的稳健选择
- **搭配 Momentum Strategy**：在 RP 基础上叠加动量信号做战术调整
- **后接 Backtesting Framework**：RP 策略需回测验证不同宏观环境下的表现
- **互补 Factor Investing**：RP 可应用于因子层面（因子风险平价），而非资产层面
- **对比 60/40**：RP 是对 60/40 的结构性改进，解决风险集中问题
