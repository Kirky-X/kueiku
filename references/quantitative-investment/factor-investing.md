# Factor Investing · 因子投资

## 核心理念

资产收益可以被少数几个系统性因子解释，通过暴露于这些因子获取风险溢价。

Fama-French 多因子模型从 CAPM 的单因子（市场）扩展到三因子（市场、规模、价值），再到五因子（加入盈利能力和投资模式）。因子投资的本质是：识别持续存在的风险溢价来源，系统性地构建组合获取这些溢价，而非依赖选股 alpha。

> **核心理念**：收益不是随机的，而是因子暴露的结果。
> 理解"为什么赚钱"比"赚了多少钱"更重要——因子归因让收益可解释、可复制、可管理。

| 因子 | 定义 | 经济逻辑 |
|------|------|---------|
| Market（MKT） | 市场超额收益 | 承担系统性风险的补偿 |
| Size（SMB） | 小市值 - 大市值 | 小公司风险更高、信息不对称更严重 |
| Value（HML） | 高账面市值比 - 低账面市值比 | 价值股承担更高基本面风险 |
| Profitability（RMW） | 高盈利 - 低盈利 | 盈利质量溢价 |
| Investment（CMA） | 保守投资 - 激进投资 | 过度投资的公司往往估值过高 |
| Momentum（MOM） | 过去赢家 - 过去输家 | 行为偏差：反应不足 + 羊群效应 |

---

## 适用场景

✅ **最适合**
- 系统性因子选股与组合构建
- 组合收益归因分析（区分 alpha 与 beta）
- Smart Beta / 因子 ETF 产品设计
- 风险因子暴露监控与管理

⚠️ **慎用**
- 因子拥挤（大量资金追逐同一因子时溢价衰减）
- 因子择时（因子轮动远比想象中困难）
- 小样本市场（因子可能需要更长时间兑现）
- 极端市场环境（因子相关性在危机时趋向 1）

## 执行步骤

### Step 1：因子选择与定义

根据投资逻辑选择因子组合：

```
经典因子库：
  价值因子：EP（盈利/价格）、BP（账面/价格）、CF/P（现金流/价格）
  动量因子：12-1 月收益、6-1 月收益、盈余动量（SUE）
  质量因子：ROE、ROA、毛利率、应计利润、资产负债率
  规模因子：市值、流通市值
  波动因子：历史波动率、特质波动率、beta
  流动性因子：换手率、Amihud 非流动性
```

> 每个因子需有经济逻辑支撑。纯数据挖掘发现的因子大概率是过拟合产物。

### Step 2：因子构建与检验

对每个候选因子做标准化检验：

```
因子构建流程：
  1. 数据清洗：去极值（MAD / 3σ）、标准化（z-score / rank）
  2. 中性化：对市值、行业做回归取残差
  3. 单因子检验：
     - IC（信息系数）：因子值与下期收益的秩相关，|IC| > 0.03 有效
     - IC_IR：IC 均值 / IC 标准差，> 0.5 为优质因子
     - 分组回测：按因子值分 5/10 组，看多空组合单调性
     - 因子衰减：不同持仓期的 IC 衰减曲线，确定调仓频率
```

### Step 3：多因子组合

将多个有效因子合成为综合信号：

```
合成方法：
  等权合成：各因子 z-score 简单平均（简单稳健）
  IC 加权：按历史 IC 或 IC_IR 加权（适应性更强）
  最优化加权：最大化 IC_IR 或夏普比率（需防过拟合）
  机器学习：非线性因子组合（见 ML Stock Selection）

组合构建：
  1. 计算每只股票的综合因子得分
  2. 按得分排序，选 Top N 或 Top X%
  3. 施加约束：行业偏离、个股权重上限、换手率约束
  4. 确定调仓频率（月度/双周/周度）
```

### Step 4：因子归因

用因子模型解释组合收益来源：

```
收益归因分解：
  组合收益 = Σ(因子暴露 × 因子收益) + 特质收益（alpha）

  Brinson 归因：配置效应 vs 选择效应
  因子归因：各因子贡献 = 因子暴露 × 因子收益率
  特质 alpha：扣除因子解释后的残差收益

  关键指标：
  - R²：因子模型解释力，> 0.8 说明因子覆盖充分
  - alpha 的 t 值：> 2.0 才统计显著
  - 因子暴露稳定性：滚动回归看暴露是否漂移
```

### Step 5：因子监控与再平衡

持续监控因子表现与风险：

```
监控维度：
  - 因子收益：滚动 3/6/12 月因子收益，识别因子衰退
  - 因子拥挤度：因子估值差（多空价差处于历史分位）
  - 因子暴露漂移：实际暴露 vs 目标暴露的偏离
  - 因子相关性：危机时因子相关性上升，分散化失效

再平衡触发：
  - 定期调仓（月度/季度）
  - 因子暴露偏离阈值（如 ±0.5σ）
  - 因子拥挤度达极端分位（如 95%+）
```

## 常见陷阱

| 陷阱 | 避免方式 |
|------|---------|
| 数据挖掘偏差 | 样本外检验 + 经济逻辑支撑，不迷信统计显著性 |
| 前视偏差（Look-ahead Bias） | 严格使用 point-in-time 数据，财务数据按发布日而非报告期末 |
| 生存偏差 | 使用包含退市股的全样本数据 |
| 因子拥挤 | 监控因子估值差历史分位，拥挤时降权 |
| 忽略交易成本 | 高换手因子需扣除实际交易成本后评估 |
| 因子择时 | 因子择时极难做到，默认等权或 IC 加权，不做主动轮动 |
| 过度中性化 | 中性化可能去掉因子的有效信息，保留经济含义 |

## 与其他方法论的关系

- **后接 Portfolio Optimization**：因子信号生成后，用均值-方差或风险平价优化权重
- **后接 Backtesting Framework**：因子组合必须经过严格回测验证
- **互补 ML Stock Selection**：机器学习可捕捉因子间非线性关系，增强因子组合
- **互补 Momentum Strategy**：动量本身是一个经典因子，可纳入多因子框架
- **前置 Financial Analysis**：基本面因子（ROE、EP 等）的构建需要财务分析基础
