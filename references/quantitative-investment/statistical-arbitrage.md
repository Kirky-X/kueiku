# Statistical Arbitrage · 统计套利

## 核心理念

利用资产之间的统计关系（协整、均值回归）构建市场中性组合，在价差偏离时建仓、回归时平仓。

统计套利的核心不是预测方向，而是预测"关系"——当两个高度相关的资产价差偏离历史均值时，做多低估的、做空高估的，等待价差回归。这与方向性策略形成本质区别：收益来源是统计关系的稳定性，而非市场方向。

> **核心理念**：交易的是关系，不是方向。
> 统计套利的 alpha 来自"价差会回归"这个统计假设。如果关系永久断裂（结构性变化），策略就会巨亏。因此，检验关系的稳定性比估计价差大小更重要。

---

## 适用场景

✅ **最适合**
- 同行业/同产业链的配对交易
- ETF 与成分股之间的套利
- 跨市场/跨品种的价差交易
- 市场中性策略（对冲掉系统性风险）

⚠️ **慎用**
- 结构性变化频繁的行业（如技术颠覆期）
- 流动性差的资产对（执行成本高）
- 价差无明确均值回归特性的组合
- 极端市场环境（相关性崩溃、价差发散）

## 执行步骤

### Step 1：配对/篮子选择

找到具有稳定统计关系的资产组合：

```
配对选择标准：
  基本面关联：
  - 同行业、同产业链、同商业模式
  - 相似的因子暴露（市值、行业、风格）
  - 共同的驱动因素（利率、商品价格）

  统计关联：
  - 历史相关性 > 0.8
  - 协整检验通过（Engle-Granger / Johansen）
  - 价差半衰期合理（5-60 个交易日）

  常见配对类型：
  - 同行业龙头：如 Coca-Cola vs Pepsi
  - ETF vs 成分股：如 SPY vs 成分股组合
  - 跨市场：如 A/H 股、ADR vs 本地股
  - 跨品种：如原油期货 vs 能源股
  - 跨期限：如近月 vs 远月期货
```

### Step 2：协整检验与价差建模

验证统计关系并建模价差动态：

```
协整检验流程：
  1. ADF 检验：确认各价格序列非平稳（I(1)）
  2. Engle-Granger 两步法：
     - 回归：ln(P_A) = α + β × ln(P_B) + ε
     - ADF 检验残差 ε 是否平稳
     - p < 0.05 → 协整关系成立
  3. Johansen 检验（多变体）：
     - 适用于多资产篮子（>2 个）
     - 检验协整秩（独立协整关系数量）

  价差（spread）定义：
  - 简单价差：spread = ln(P_A) - β × ln(P_B)
  - 标准化价差：z = (spread - mean) / std
  - OU 过程建模：d(spread) = θ(μ - spread)dt + σdW
    θ = 均值回归速度，μ = 长期均值

  半衰期 = ln(2) / θ
  半衰期过短（< 5 天）→ 交易成本可能吞噬利润
  半衰期过长（> 120 天）→ 回归太慢，风险暴露过久
```

### Step 3：交易信号生成

基于价差偏离程度生成开仓/平仓信号：

```
信号规则（均值回归型）：
  开仓条件：
  - 做多价差：z < -entry_threshold（如 -1.5σ）
    即价差低于均值，预期价差扩大（A 相对 B 被低估）
  - 做空价差：z > +entry_threshold（如 +1.5σ）
    即价差高于均值，预期价差缩小

  平仓条件：
  - 止盈：|z| < exit_threshold（如 0.5σ，价差回归均值）
  - 止损：|z| > stop_loss_threshold（如 3σ，价差继续发散）
  - 时间止损：持仓超过 N 天未回归

  仓位管理：
  - 固定仓位：每次开仓固定金额
  - 波动率调整：仓位 = 目标风险 / 价差波动率
  - 分批建仓：z 达到 -1.5σ 建 50%，到 -2σ 加到 100%
```

### Step 4：风险管理与监控

统计套利不是"无风险"套利：

```
核心风险：
  1. 结构性断裂（regime change）：
     - 价差永久偏离，不回归
     - 检测：滚动协整检验、CUSUM 检验
     - 应对：硬止损 + 定期重新检验协整关系

  2. 流动性风险：
     - 两腿执行不同步（legging risk）
     - 应对：同时下单、限价单、降低持仓规模

  3. 融资风险：
     - 做空腿被召回（short squeeze）
     - 应对：分散做空标的、预留备用标的

  4. 模型风险：
     - β 估计不稳定
     - 应对：滚动估计 β、多模型交叉验证

  监控指标：
  - 价差 z-score 实时位置
  - 协整 p-value 滚动变化
  - 半衰期变化趋势
  - 持仓盈亏与 VaR
```

### Step 5：绩效评估

统计套利策略的评估维度：

```
关键指标：
  - 夏普比率：> 1.5 为优秀（市场中性策略）
  - 最大回撤：< 5%（市场中性应低回撤）
  - 胜率：> 55%
  - 盈亏比：> 1.5:1
  - 平均持仓天数：< 30 天（均值回归策略）
  - 年化换手：反映交易频率
  - 交易成本占比：应 < 收益的 30%

  稳定性检验：
  - 滚动 6 月夏普比率是否稳定
  - 分市场环境表现（趋势市/震荡市/危机）
  - 不同配对的收益贡献是否分散
```

## 常见陷阱

| 陷阱 | 避免方式 |
|------|---------|
| 伪回归（spurious regression） | 必须先做协整检验，不能只看相关性 |
| 忽略结构性变化 | 定期重新检验协整关系，加入 CUSUM 监控 |
| 半衰期过短 | 半衰期 < 5 天的配对扣除交易成本后可能无利 |
| 两腿执行不同步 | 使用算法交易同时下单，或用 ETF 替代篮子 |
| 过度优化参数 | 开仓/平仓阈值需稳健性检验，不用最优化值 |
| 忽视做空成本 | 做空有借券成本 + 召回风险，必须计入 |
| 配对太少 | 单一配对风险集中，建议 10+ 配对分散化 |

## 与其他方法论的关系

- **后接 Backtesting Framework**：统计套利策略必须经过严格回测，尤其关注结构断裂期
- **互补 ML Stock Selection**：机器学习可增强配对选择和信号生成
- **对比 Momentum Strategy**：动量追趋势，统计套利赌回归，两者可组合降低相关性
- **互补 Factor Investing**：统计套利可视为市场中性因子策略的特殊形式
- **前置 Financial Analysis**：基本面分析帮助判断配对关系的经济逻辑是否成立
