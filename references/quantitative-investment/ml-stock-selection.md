# ML Stock Selection · 机器学习选股

## 核心理念

用机器学习模型从高维特征中提取非线性关系，预测股票收益或涨跌方向。

传统线性因子模型假设因子与收益的关系是线性的、可加的。机器学习能捕捉因子间的交互效应和非线性模式——例如"低估值 + 高动量"的组合效应可能强于两者简单相加。但 ML 选股的核心挑战不是模型复杂度，而是金融数据的低信噪比和非平稳性。

> **核心理念**：金融数据不是图像识别——信噪比极低，分布持续漂移。
> ML 选股的成功关键不在于模型多复杂，而在于特征工程的质量、防过拟合的严格程度、以及对非平稳性的处理。简单模型 + 好特征 > 复杂模型 + 原始数据。

---

## 适用场景

✅ **最适合**
- 多因子非线性组合（因子间存在交互效应）
- 高维特征空间（数百个候选因子）
- 另类数据整合（文本、情绪、卫星等）
- 日内/周频中频选股

⚠️ **慎用**
- 样本量不足（个股时间序列短、截面股票数少）
- 需要可解释性的场景（监管要求、投资委员会解释）
- 极端市场环境（训练数据不涵盖的 regime）
- 低频策略（月频以下，ML 优势不明显）

## 执行步骤

### Step 1：特征工程

特征工程是 ML 选股最重要的环节，比模型选择更重要：

```
特征类别：
  基本面特征：
  - 估值：EP, BP, SP, CFP, EV/EBITDA
  - 盈利：ROE, ROA, 毛利率, 净利率, 应计利润
  - 成长：营收增速, 利润增速, SUE（标准化意外盈利）
  - 质量：资产负债率, 现金流/利润, 审计意见

  技术面特征：
  - 动量：1/3/6/12 月收益, 52 周高点距离
  - 波动：历史波动率, 特质波动率, 已实现偏度
  - 流动性：换手率, Amihud 非流动性, 买卖价差
  - 量价：OBV, VWAP 偏离, 大单净流入

  另类数据特征：
  - 文本情绪：财报/新闻/社交媒体情绪得分
  - 分析师：预期修正方向、一致预期变化
  - 资金流：北向资金、融资融券余额变化
  - 行业特征：行业动量、行业估值分位

  宏观特征：
  - 利率期限利差、信用利差
  - 宏观经济指标（PMI、CPI）
  - 市场状态指标（波动率指数、市场情绪）

  特征处理：
  1. 去极值：MAD 法（中位数绝对偏差）
  2. 标准化：z-score 或 rank 标准化
  3. 中性化：对市值、行业回归取残差
  4. 缺失值：行业中位数填充 / 前值填充
  5. 滞后对齐：确保特征值领先于收益率（避免前视偏差）
```

> 特征数量不是越多越好。每个特征需有经济逻辑支撑。200 个无逻辑的特征中大概率 195 个是噪声。

### Step 2：标签定义

定义模型要预测的目标变量：

```
标签类型：
  回归型（预测收益率）：
  - 下期收益：R(t+1) = 下一期收益率
  - 风险调整收益：R(t+1) / σ(t)（夏普化）
  - 超额收益：R_stock - R_benchmark

  分类型（预测涨跌）：
  - 二分类：R(t+1) > 0 → 1，否则 0
  - 三分类：Top 30% → 1，Bottom 30% → -1，中间 → 0
  - 多分类：按收益分 5/10 组

  排序型（预测排名）：
  - ListMLE / LambdaMART：直接优化排序指标

  选择建议：
  - 分类比回归更稳健（减少极端值影响）
  - 三分类比二分类信息更丰富
  - 排序型直接优化选股能力
```

### Step 3：模型选择与训练

选择合适的 ML 模型并训练：

```
常用模型（按复杂度递增）：
  线性模型：
  - Lasso / Ridge / ElasticNet：带正则化的线性模型
  - 优势：可解释、稳健、不易过拟合
  - 适用：特征线性关系为主、样本量小

  树模型（最常用）：
  - Random Forest：集成学习，稳健
  - XGBoost / LightGBM：梯度提升树，性能强
  - 优势：自动处理非线性、特征交互、对异常值稳健
  - 适用：大多数选股场景

  深度学习：
  - LSTM / GRU：时序特征
  - Transformer：长程依赖
  - GNN：股票关系图结构
  - 优势：复杂模式、端到端学习
  - 风险：极易过拟合，需大量数据和严格正则化

  训练要点：
  - 时间序列分割：不能随机 split，必须按时间（训练集 < 测试集）
  - Purged K-Fold：训练集和验证集之间留缓冲期（防数据泄露）
  - 早停：验证集 loss 不再下降时停止
  - 正则化：L1/L2、dropout、最小叶子节点数
```

### Step 4：模型评估与选择

用多维度指标评估模型：

```
预测能力指标：
  - IC（信息系数）：预测值与实际收益的秩相关，> 0.05 有效
  - IC_IR：IC 均值 / IC 标准差，> 0.5 为优秀
  - Rank IC：对极端值更稳健
  - 分组单调性：按预测值分 5/10 组，收益是否单调递增
  - AUC（分类任务）：> 0.55 有效，> 0.60 优秀

  组合层面指标：
  - Top 组年化收益（扣成本后）
  - Top-Bottom 多空收益
  - 信息比率

  模型选择原则：
  - 优先选简单模型（Occam's Razor）
  - 复杂模型必须在样本外显著优于简单模型
  - 集成多模型（stacking）通常优于单一最优模型
```

### Step 5：组合构建与实盘

将 ML 预测转化为可执行的组合：

```
组合构建：
  1. 用训练好的模型预测所有股票的信号值
  2. 按信号值排序，选 Top N
  3. 权重方案：等权 / 信号加权 / 风险平价
  4. 约束：行业偏离、个股权重上限、换手率

  模型更新策略：
  - 滚动训练：每月/每季度用最新数据重新训练
  - 增量更新：在线学习，新数据增量更新模型
  - 集成更新：多模型加权，定期调整模型权重

  实盘监控：
  - 预测 IC 的实时衰减
  - 特征重要性漂移（模型结构变化）
  - 组合换手与交易成本
  - 模型预测分布变化（概念漂移检测）
```

## 常见陷阱

| 陷阱 | 避免方式 |
|------|---------|
| 前视偏差 | 特征严格使用历史数据，标签与特征时间对齐 |
| 数据泄露 | Purged K-Fold，训练集和测试集间留缓冲期 |
| 过拟合 | 简单模型优先，复杂模型需样本外显著优于简单模型 |
| 忽略非平稳性 | 金融数据分布持续漂移，需滚动训练 + 漂移检测 |
| 特征工程不足 | 特征质量 > 模型复杂度，80% 精力放在特征工程 |
| 随机划分训练/测试 | 必须按时间划分，不能随机 split |
| 追求单一最优模型 | 集成多模型更稳健，避免模型选择偏差 |
| 忽略可解释性 | 用 SHAP / 特征重要性解释模型决策，否则难以信任 |

## 与其他方法论的关系

- **前置 Factor Investing**：因子是 ML 的核心输入特征，因子质量决定 ML 上限
- **后接 Portfolio Optimization**：ML 预测信号作为预期收益输入，用 MVO 优化权重
- **后接 Backtesting Framework**：ML 模型必须经过严格回测，尤其关注过拟合
- **互补 Statistical Arbitrage**：ML 可增强配对选择和信号生成
- **前置 Financial Analysis**：基本面特征是 ML 选股的重要特征来源
