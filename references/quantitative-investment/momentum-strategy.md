# Momentum Strategy · 动量策略

## 核心理念

资产价格在中期（3-12 个月）存在趋势延续效应——过去涨的继续涨，过去跌的继续跌。

动量是金融市场最持久的异象之一，跨越资产类别、时间跨度和市场结构均存在。行为金融学解释为：投资者对信息反应不足（导致趋势形成）和过度反应（导致趋势反转）。动量策略的本质是系统性地利用这种可预测性。

> **核心理念**：趋势是真实的，但崩溃也是真实的。
> 动量策略赚取的是"趋势延续"的溢价，代价是承担"动量崩溃"的尾部风险。理解这个 trade-off 是执行动量策略的前提。

---

## 适用场景

✅ **最适合**
- 趋势跟踪与择时
- 跨资产轮动（行业/国家/风格）
- 作为多因子框架的增强信号
- 管理期货（CTA）策略

⚠️ **慎用**
- 高波动震荡市（动量频繁反转）
- 动量崩溃高发期（市场拐点、政策急转）
- 低流动性资产（交易成本高侵蚀动量收益）
- 极短持仓期（日频动量噪声太大）

## 执行步骤

### Step 1：定义动量信号

选择回看期和信号构造方式：

```
经典动量信号：
  价格动量：
  - 12-1 月动量：过去 12 个月收益（跳过最近 1 个月）
    跳过近 1 月原因：短期（1 周内）存在反转效应
  - 6-1 月动量：过去 6 个月收益（跳过近 1 月）
  - 12-6 月动量：7-12 月前的收益（中期趋势）

  风险调整动量：
  - 信息比率动量：过去 N 月收益 / 波动率
  - 特质动量：收益对因子模型回归的残差累积（去除因子暴露）

  其他变体：
  - 盈余动量（SUE）：盈利超预期幅度的持续性
  - 分析师修正动量：盈利预期上调/下调的趋势
  - 52 周高点：当前价格距 52 周高点的距离
```

> 12-1 月动量是学术文献中最稳健的，但不同市场的最佳回看期可能不同。建议测试多个回看期，选择稳健表现而非最优表现。

### Step 2：构建多空组合

按动量信号排序构建组合：

```
组合构建：
  1. 计算所有股票的动量信号值
  2. 按信号值排序
  3. 做多 Top 组（如 Top 20%），做空 Bottom 组（或仅做多 Top 组）
  4. 组内等权或市值加权

  行业中性化（推荐）：
  - 在每个行业内做动量排序
  - 避免组合偏向特定行业（动量信号本身与行业轮动相关）

  权重方案：
  - 等权：简单，但偏向小盘
  - 市值加权：偏向大盘，降低换手
  - 信号强度加权：动量越强权重越高
  - 风险平价加权：按波动率倒数加权
```

### Step 3：动量崩溃风险管理

动量策略的最大风险是动量崩溃（momentum crash）：

```
动量崩溃特征：
  - 市场急跌后快速反弹（如 2009 年 3 月）
  - 过去的输家（已超跌）暴涨，过去的赢家回调
  - 崩溃往往发生在经济拐点

  风险管理工具：
  1. 波动率缩放：高波动时降低动量仓位
     仓位 = 目标仓位 × (目标波动率 / 当前动量组合波动率)
  2. 趋势过滤：市场低于 200 日均线时降低动量暴露
  3. 价值对冲：同时持有价值因子多头，对冲动量崩溃
  4. 尾部对冲：买入虚值看涨期权（保护做空腿）
  5. 分散化：跨资产类别做动量（股票+债券+商品）

  核心原则：不要在高波动期维持满仓动量
```

### Step 4：回测与参数稳健性

验证动量策略的有效性：

```
回测要点：
  - 样本内 + 样本外分段验证
  - 多个回看期（3m/6m/12m）的稳健性
  - 扣除交易成本后的净收益
  - 分年度表现（避免只看好平均）
  - 动量崩溃期的最大损失

  关键指标：
  | 指标 | 合格标准 |
  |------|---------|
  | 多空年化收益 | > 5%（扣成本后） |
  | 信息比率 | > 0.5 |
  | 最大回撤 | < 20%（多空） |
  | 月度胜率 | > 55% |
  | 崩溃期损失 | < 15%（有风控） |
  | 跨市场一致性 | 多数市场正收益 |
```

### Step 5：实盘实施

动量策略的实盘注意事项：

```
实施细节：
  调仓频率：月度最常用（换手与信号衰减的平衡）
  交易成本估算：
  - 佣金 + 印花税
  - 冲击成本：小盘股尤其重要
  - 滑点：信号日到执行日的价差
  
  换手控制：
  - 缓冲区间：排名变化不大时不调仓
  - 部分调仓：只调整排名变化大的持仓
  - 换手约束：单次调仓换手 ≤ 30%
  
  容量评估：
  - 策略 AUM / 持仓股票日均成交额
  - 参与率 ≤ 10%（避免市场冲击）
```

## 常见陷阱

| 陷阱 | 避免方式 |
|------|---------|
| 不跳过近期月份 | 近 1 月存在反转效应，必须跳过 |
| 忽略动量崩溃 | 必须实施波动率缩放或趋势过滤 |
| 回看期过拟合 | 测试多个回看期，选稳健的而非最优的 |
| 忽略交易成本 | 高换手动量策略扣成本后可能无效 |
| 行业集中 | 不做行业中性化会导致组合偏向热门行业 |
| 用等权不分行业 | 小盘股主导等权动量收益，加入市值加权对比 |
| 只看平均收益 | 必须看分年度和崩溃期表现 |

## 与其他方法论的关系

- **互补 Factor Investing**：动量是经典因子之一，可纳入多因子框架
- **互补 Risk Parity**：动量信号可用于 Risk Parity 的战术资产配置层
- **后接 Backtesting Framework**：动量策略必须经过严格回测验证
- **互补 Statistical Arbitrage**：动量（趋势延续）和均值回归是两种对立策略，可组合使用
- **前置 Momentum + Black-Litterman**：动量信号可编码为 BL 模型中的投资者观点
