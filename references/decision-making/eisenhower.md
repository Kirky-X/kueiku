# Eisenhower Matrix

## Core Concept
Time management using Importance × Urgency 4-quadrant classification: Do (important+urgent), Schedule (important+not urgent), Delegate (not important+urgent), Eliminate (not important+not urgent).

## Applicable Scenarios
✅ **Best for**
- Personal/team task management
- Resource allocation decisions
- Time management improvement

⚠️ **When NOT to use**
- Tasks with wildly different effort or consequence sizes — a 5-minute email and a quarter-long project don't share a quadrant; bucket by scale first
- Parallel identical workstreams — throughput queueing (WIP limits) fits better than 2×2 sorting
- Using it as the team's only prioritization tool — it sequences work but cannot value it; pair with RICE/MoSCoW for the what, not just the when

## Key Steps
1. List all current tasks
2. For each task, assess: Is it important? (does it contribute to long-term goals?)
3. For each task, assess: Is it urgent? (does it require immediate attention?)
4. Place each task in the appropriate quadrant
5. Act: Do Q1 tasks now, Schedule Q2 tasks, Delegate Q3 tasks, Eliminate Q4 tasks

## Output Template

```
Q1 Do (important + urgent)          — cap: [n], else escalate/renegotiate
  1. [prod incident] — owner [x], by [today]
Q2 Schedule (important, not urgent) — the growth quadrant; timebox: [calendar blocks protected]
  1. [quarterly architecture review] — block: [Fri 10-12]
Q3 Delegate (not important, urgent) — delegate to [who], with what authority
  1. [vendor scheduling] → [ops] — full authority
Q4 Eliminate (neither)              — say no explicitly
  1. [reply-all thread] — dropped

Q1 source check: how many Q1 items originated as neglected Q2 items? [answer — the real lever]
```

## Failure Modes
- Importance judged by requester loudness — Q3 tasks arrive dressed as Q1 → define importance against written goals before sorting; loudness is urgency's costume
- Q2 perpetually postponed: the quadrant gets scheduled, then sacrificed to Q1 fires → protect Q2 with calendar blocks reviewed weekly, or the matrix only accelerates firefighting
- Elimination never happens: Q4 items linger out of guilt → deletion is the quadrant's action; if nothing was dropped this week, re-examine the sort

## Evidence Strength
Practitioner consensus — a widely taught heuristic whose value is the important/urgent distinction itself (documented failure mode: urgent crowds out important); the 2×2 packaging and quadrant prescriptions are convention, and there is no controlled evidence that matrix use alone improves productivity — its effect runs through protecting Q2 time.

## Source
Attributed to Dwight D. Eisenhower; popularized by Stephen Covey in *The 7 Habits of Highly Effective People*.
