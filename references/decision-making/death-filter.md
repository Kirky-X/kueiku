# Death Filter

## Core Concept
An existential decision filter: "If this were the last decision I ever make, would I still choose this?" Forces confrontation with mortality to clarify true values and priorities. Not for daily decisions — reserved for major, irreversible life/career/startup decisions.

## Applicable Scenarios
✅ **Best for**
- Major life decisions
- Career direction choices
- Startup direction decisions

⚠️ **When NOT to use**
- The decision is a quantifiable trade-off wearing values clothing — the filter ranks by existential resonance and will bless an option that is numerically ruinous; run **Decision Tree & Expected Value** first, then apply the filter to the surviving candidates
- Group decisions — "whose deathbed?" has no answer, and one person's terminal values get laundered as the team's; use **Decision Matrix** with elicited weights instead
- The option set is not yet real (no concrete alternatives to weigh) — the filter ranks options, it does not generate them; diverge first
- Assumed irreversibility — many "one-way doors" are two-way at a known cost; grade with **Reversibility Grading** before spending existential weight

⚠️ **Not for**
- Daily operational decisions
- Urgent/time-critical decisions
- Reversible decisions

## Key Steps
1. Confirm this is a major, irreversible decision (not daily/urgent)
2. List all candidate options
3. Apply the Death Filter to each: "On my deathbed, would I regret NOT choosing this?"
4. Rank options by existential resonance
5. Validate: does the top option align with your core values?
6. Commit to the decision

## Output Template

```
Decision: [the one major, irreversible choice on the table]
Options: [A / B / C — concrete, not straw alternatives]
Death Filter per option: "On my deathbed, would I regret NOT choosing this?"
  [A]: [yes/no + the value it serves or violates, one line]
  [B]: [yes/no + why]
Ranking by existential resonance: [A > B > C]
Values check: top option aligns with [named core values] — [holds / conflict noted]
Commitment: [decision + what you stop doing to make it real]
```

## Failure Modes
- Regret answered by present fear: "would I regret not choosing this?" returns current anxiety (fear of missing out, fear of failure), not terminal values → restate as "at 90, looking back, which choice do I want to have made?" and write each option's answer before comparing
- Existential gravity on small decisions: everything gets deathbed framing until the filter stops filtering → reserve it for options that fail **Reversibility Grading**'s one-way-door test; everything else gets decided normally
- Post-hoc blessing: the option was already chosen and the ritual just sanctifies it → run the filter per option independently and in writing before ranking; let an option die if it fails
- Values never named: "existential resonance" stays vague, so the ranking is vibes → name the 2-3 core values the filter serves before applying it

## Evidence Strength
Contested — popular as a reflection prompt (Jobs' deathbed speech, existential decision-making traditions) with no research validating deathbed simulation as a decision aid; affective-forecasting research shows people systematically mispredict what they will regret, which undercuts the premise that imagined deathbed regret tracks real values. Treat it as values clarification for genuinely irreversible choices, not as a validated instrument.
