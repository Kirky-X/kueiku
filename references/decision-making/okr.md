# OKR — Objectives and Key Results

## Core Concept
Goal-setting framework: Objectives define "what we want to achieve" (qualitative, inspiring), Key Results define "how we'll measure progress" (quantitative, time-bound). Typically set quarterly.

## Applicable Scenarios
✅ **Best for**
- Quarterly/annual goal setting
- Team alignment
- Tracking progress toward strategic goals

⚠️ **When NOT to use**
- The metrics are already agreed and on track — keep a dashboard; OKR buys focus and stretch, not bookkeeping
- Compensation or performance reviews tie directly to KR scores — sandbagging follows within a quarter; keep OKR and pay on separate tracks
- The team cannot commit to fewer than five Objectives — that is a prioritization failure (RICE / MoSCoW); OKR on an unpruned list is focus theater
- The open question is which metrics strategy should even be measured on → run the Balanced-Scorecard Recipe below first, then let OKR move the chosen metrics

## Key Steps
1. Define 3-5 Objectives (qualitative, inspiring, time-bound)
2. For each Objective, define 2-5 Key Results (quantitative, measurable)
3. Key Results should be ambitious (70% achievement = good)
4. Assign owners for each KR
5. Review weekly/monthly; adjust if needed
6. End-of-quarter retrospective: score each KR 0-1.0

## Output Template

```
Objective: [qualitative, inspiring, time-bound]
  KR1: [metric from X to Y by date] — owner: [name]
  KR2: [...] (2-5 per Objective)
Confidence at check-in: [per-KR estimate + current blocker]
Quarter score: [0.0-1.0 per KR]
```

## Failure Modes
- Sandbagged KRs: writing what would happen anyway defeats the 70% stretch rule → score honestly; four straight quarters above 0.9 means these are commitments, not Objectives
- Task-list KRs ("launch the export feature") with no measurable outcome → force the "from X to Y" form; output masquerading as outcome
- Pay-linked KRs: gaming and sandbagging within one cycle → separation from compensation is design, not plea
- Objective inflation: 6+ Objectives per team → nothing is a priority; cap 3-5 per org, fewer per team
- Set-and-forget: no weekly check-in cadence → dead by week 3; the review ritual is the system

## Evidence Strength
**Practitioner consensus on adoption, mixed on causal lift.** The Grove/Doerr lineage and decades of industry use are well documented; evidence that OKR itself raises performance is confounded by selection effects and by the measurement/focus practices it bundles — treat the cadence and the stretch rule as the active ingredients.
