# Risk Matrix · 风险矩阵

## 核心理念

风险 = 概率 × 影响。不是所有风险都需要 FMEA 级别的工程分析，也不是所有决策都需要 Pre-mortem 的想象预演。风险矩阵提供轻量级的 2 维风险评估，快速排序并分配应对资源。

> "不是所有重要的东西都能被计算，也不是所有能被计算的东西都重要。" —— Albert Einstein

## 适用场景

✅ **最适合**
- 项目启动前的初步风险筛选
- 战略规划中的风险全景扫描
- 技术选型中的风险对比
- Pre-mortem 后的风险量化排序
- 资源有限需聚焦高优先级风险

⚠️ **慎用**
- 需要系统级失效分析（用 FMEA，三维度更精确）
- 需要想象式风险预演（用 Pre-mortem，更直觉）
- 风险之间高度关联（需搭配 Systems Thinking 分析耦合）
- 需要统计建模的量化风险（用 Monte Carlo 模拟）

## 执行步骤

### Step 1：列举风险

头脑风暴所有已识别风险，不限数量。

```
风险来源：
  历史经验：过去出过什么问题？
  专家判断：领域专家担心什么？
  Pre-mortem 输出：想象失败场景中的风险因素
  检查清单：行业常见风险清单
  依赖分析：外部依赖失败的可能性

格式：
  每条风险用"[事件] 因为 [原因] 导致 [后果]"描述
```

### Step 2：定义刻度

为概率和影响定义 1-5 的具体标准（避免主观偏差）。

```
概率刻度（示例）：
  5 = 几乎确定（>80%）—— 过去 12 个月内发生过
  4 = 很可能（60-80%）—— 过去 2 年内发生过
  3 = 可能（40-60%）  —— 过去 3-5 年内发生过
  2 = 不太可能（20-40%）—— 过去 5-10 年内发生过
  1 = 罕见（<20%）    —— 无已知先例

影响刻度（示例，按项目维度）：
  5 = 灾难性 —— 项目失败 / 损失 > 预算 50%
  4 = 重大   —— 严重延期 / 损失 30-50%
  3 = 中等   —— 可控延期 / 损失 10-30%
  2 = 轻微   —— 可吸收 / 损失 5-10%
  1 = 可忽略 —— 无实质影响 / 损失 < 5%
```

> 刻度必须根据具体场景定制，上述仅为通用示例。

### Step 3：逐条评估

对每条风险评估概率和影响。

```
评估原则：
  独立评估：每条风险独立打分，不受其他风险影响
  保守原则：不确定时倾向高估（宁可多关注不可遗漏）
  多人校准：至少 2 人独立评估后取均值/讨论分歧
  标注依据：每条打分附一句话理由
```

### Step 4：排序与分区

按风险值（概率 × 影响）排序，划入 4 个区域。

```
分区标准：
  红色（极高风险）：风险值 15-25 → 立即行动，分配专人应对
  橙色（高风险）  ：风险值 8-14  → 主动缓解，制定应对计划
  黄色（中风险）  ：风险值 4-7   → 监控，设定触发条件
  绿色（低风险）  ：风险值 1-3   → 接受，定期复查
```

### Step 5：制定应对策略

为红色和橙色风险制定具体应对措施。

```
4T 应对策略：
  Treat（处理）  → 采取行动降低概率或影响（红/橙色首选）
  Transfer（转移）→ 通过保险/外包/合同转移风险
  Tolerate（容忍）→ 接受风险，设定监控指标和触发条件
  Terminate（终止）→ 消除风险源（如放弃某技术路线）

每条应对措施需明确：
  负责人、截止日期、触发条件、降级方案
```

## 常见陷阱

| 陷阱 | 避免方式 |
|------|---------|
| 概率和影响全靠拍脑袋 | 定义具体刻度标准 + 多人校准 |
| 忽视风险间的相关性 | 标注风险间的因果关系（搭配 Systems Thinking） |
| 只关注负面风险 | 同时识别正面风险（机会），用 4T 策略中的 Transfer/Terminate |
| 评估完就束之高阁 | 设定复查周期（至少每月），风险矩阵是活文档 |
| 所有风险都标"高" | 强制排序——只有 Top 20% 能标红色 |

## 与其他方法论的关系

- **搭配 FMEA**：风险矩阵做初步筛选（2 维快速），FMEA 做深度分析（3 维精确）
- **搭配 Pre-mortem**：Pre-mortem 识别风险（想象式），风险矩阵量化排序（评估式）
- **搭配 Second-Order Thinking**：评估风险应对方案的连锁效应
- **搭配 Systems Thinking**：分析风险间的反馈环路和耦合关系
- **搭配 Decision Matrix**：风险矩阵评估风险，Decision Matrix 评估方案
