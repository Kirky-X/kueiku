# User Research

**When to use**: Deep understanding of user needs, behaviors, pain points

| Methodology | One-line description | Best scenario | Reference |
| --- | --- | --- | --- |
| **Customer Journey Map** | Full user journey touchpoints, emotions, and pain points visualized | Service optimization, product experience design, cross-department alignment | `customer-journey.md` |
| **Empathy Map** | User's Say/Do/Think/Feel 4-dimension profile | User research kickoff, persona supplementation | `empathy-map.md` |
| **Consumer Decision Journey** | Consider→Evaluate→Purchase→Experience→Advocate non-linear decision journey | Journey optimization, touchpoint design, churn analysis, loyalty loop design | `consumer-decision-journey.md` |
| **Maslow Hierarchy** | Physiological→Safety→Love/Belonging→Esteem→Self-Actualization 5-level needs | User need mining, product positioning, marketing appeal design, upgrade path planning | `maslow-hierarchy.md` |

## Minimum Information Requirements per Methodology

- **Customer Journey Map**: Requires observable user behavior path data or interviews
- **Empathy Map**: Requires at least 1-2 user interview records
- **Consumer Decision Journey**: Requires per-stage touchpoints + experience scores + churn data
- **Maslow Hierarchy**: Requires user interview/behavior data/review mining to determine dominant need level

## Routing Trigger Signals

- "User journey mapping" → Customer Journey Map (primary)
- "Understanding user feelings / pain point empathy" → Empathy Map (primary) ⚡ If need to uncover users' "jobs" → use JTBD (Product & Growth)
- "User persona" (backup) → Empathy Map (as persona supplement) ⚡ If need complete user archetype description → use User Personas (Market Research)
- "Decision journey optimization / touchpoint design / churn analysis" → Consumer Decision Journey (primary)
- "User need mining / marketing appeal design / need hierarchy" → Maslow Hierarchy (primary)

## Common Combinations

- **Need mining**: Empathy Map → Customer Journey → JTBD
- **Service optimization**: Customer Journey → SCAMPER (creative improvement)
- **Need level positioning**: Empathy Map → Maslow Hierarchy → User Personas
- **Decision journey optimization**: Consumer Decision Journey → RFM Model (identify key groups) → A/B Test (touchpoint validation)

## Methodology Mutual Exclusion and Ordering Constraints

| Constraint pair | Rule | Reason |
| --- | --- | --- |
| Empathy Map → JTBD | **Empathy Map first, then JTBD** (need mining scenario) | Empathy Map builds user empathy foundation; JTBD then digs deeper into functional/emotional jobs |
| Empathy Map vs User Personas | **Empathy Map supplements User Personas**, not replaces it | Empathy Map focuses on feeling empathy; Personas focus on complete profile; output purposes differ |
