# Empathy Map

## Core Concept
4-dimension user profile: Say / Do / Think / Feel. Forces the team to go beyond demographics and truly empathize with the user's experience. Built from interview data, not assumptions.

## Applicable Scenarios
✅ **Best for**
- User research kickoff
- Persona supplementation
- Building user empathy in teams

⚠️ **When NOT to use**
- No interview data — filling quadrants from imagination is assumption mapping, not empathy; run interviews first (**The Mom Test** format works)
- Making positioning or prioritization decisions — the map builds shared understanding, not decision-grade output; use **JTBD** or the **Value Proposition Canvas** for that
- One map for a whole segment — users within a segment vary; build per persona and label the evidence base
- Alignment theater — a one-hour workshop with no follow-through produces a poster; convert contradictions into research questions or design decisions

## Key Steps
1. Conduct 1-2 user interviews (minimum)
2. Create a large 4-quadrant canvas: Say / Do / Think / Feel
3. Populate each quadrant with direct quotes and observations from interviews
4. Identify contradictions (e.g., says X but does Y)
5. Synthesize key insights: what does the user really care about?
6. Use as input for personas, JTBD, or design decisions

## Output Template

```
User: [persona/segment]  Evidence base: [# interviews, dates]
SAY: [direct quotes, verbatim]
DO: [observed behaviors, from logs or observation]
THINK: [beliefs and concerns — inferred, marked as inference]
FEEL: [emotional states + the moment that triggers them]
Contradictions: [says X but does Y → what it implies]
Insights: [one line each, evidence-linked]
Handoff: [feeds which persona / JTBD statement / design decision]
```

## Failure Modes
- Invention in disguise: quadrants filled from team imagination → every cell must trace to a quote or observation; mark Think/Feel inferences explicitly and verify them in the next round
- Taking SAY at face value: what users say conflicts with what they do → treat contradictions as the highest-value output, not noise to smooth over
- One vivid interview generalized: a single story becomes "the user" → aggregate per segment and note the n behind the map
- Canvas as endpoint: the map gets hung up and nothing changes → convert insights into JTBD statements, design decisions or research questions with owners

## Evidence Strength
Practitioner consensus — the empathy map is a widely used synthesis and team-alignment tool in design practice with no formal psychometric validation; it is a strong thinking scaffold and a weak data source — its value depends entirely on being grounded in real interview and observation data.
