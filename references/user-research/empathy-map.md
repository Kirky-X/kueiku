# Empathy Map

## Core Concept
4-dimension user profile: Say / Do / Think / Feel. Forces the team to go beyond demographics and truly empathize with the user's experience. Built from interview data, not assumptions.

## Applicable Scenarios
✅ **Best for**
- User research kickoff
- Persona supplementation
- Building user empathy in teams

## Key Steps
1. Conduct 1-2 user interviews (minimum)
2. Create a large 4-quadrant canvas: Say / Do / Think / Feel
3. Populate each quadrant with direct quotes and observations from interviews
4. Identify contradictions (e.g., says X but does Y)
5. Synthesize key insights: what does the user really care about?
6. Use as input for personas, JTBD, or design decisions

## Source
Dave Gray, *Gamestorming* (2010); Stanford d.school empathy mapping tool.
