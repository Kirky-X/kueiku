# Kueiku — Methodology Compass

> A methodology navigation map for AI agents: pick the right framework first, then use it correctly. An index of 142 methodologies across 19 categories with selection routing, a calling protocol, an information-insufficient degradation path, and a framework correction mechanism.

## ✨ Features

- **142 methodologies across 19 categories**: one `references/<category>/<methodology>.md` per methodology (execution steps + output template), read on demand, never preloaded; counts are generated by `scripts/count_methodologies.py` (`methodology-count.json`)
- **Quick routing table**: task type → primary + backup framework, selection in under 30 seconds (see [SKILL.md](SKILL.md))
- **Calling protocol**: declare → read reference → gather inputs → execute → gated output, a five-step standard flow that makes methodology usage traceable
- **Degradation path for insufficient information**: 4 levels — execute normally → label assumptions and to-collect items → stop and ask key questions → fall back to best judgment; never force a framework
- **Framework correction mechanism**: if a framework turns out to be a poor fit mid-execution (a key dimension cannot be filled, the conclusion drifts, the user rejects the direction), stop immediately, explain, and re-route
- **Combination rules**: common methodology combos plus mutually exclusive pairs (Lean Canvas ↔ Startup Canvas: pick one; ICE rough screening → RICE fine ranking)
- **Computation CLI** (`kueiku-calc`, 19 subcommands): RICE / Decision Matrix / ICE / Risk Matrix / FMEA / Pareto / DuPont / DCF / EVA / A-B Test / RFM / Cohort / Opportunity Score / BCG / GE-McKinsey / Factor Analysis / Momentum / Risk Parity / Performance Metrics

## 📦 Installation

```bash
# Option 1: one-command deploy from this repository root
# (syncs to ~/.zcode/skills/ and ~/.claude/skills/, LF-normalized)
bash scripts/sync-skills.sh kueiku

# Option 2: manual copy into an agent skills directory
cp -r kueiku/ ~/.zcode/skills/kueiku/
# Option 3: Remote install (GitHub repo)
npx skills add Kirky-X/kueiku --agent claude-code -y
```

First-run requirements: Python 3.8+ only (the CLI uses the standard library exclusively); no requirements.txt.

## 🚀 Quick Start

Prerequisite: the skill is deployed to an agent skills directory; trigger it with natural language in a skills-aware agent session.

```text
Analyze our overseas strategy with SWOT     # routes → Strategic Analysis → swot
Which of these three features first?        # routes → Decision Making → RICE
Segment this user base                      # routes → Data Analysis → RFM
```

Computation-heavy methodologies run directly via the CLI (deterministic, reproducible, CSV input):

```bash
python3 ~/.zcode/skills/kueiku/scripts/main.py rice -i items.csv     # RICE priority scoring
python3 ~/.zcode/skills/kueiku/scripts/main.py abtest -i ab.csv --json   # A/B significance + SRM check
# ab.csv format: variant,users,conversions with two rows (control / treatment)
```

### Calling Protocol (five steps)

The five-step standard flow once a methodology is selected:

```text
0. Pre-check    → task type matches the routing table; confirm information sufficiency
1. Declare      → state which methodology is used and why
2. Read ref     → extract execution steps and the output template
3. Gather input → confirm each required input item by item; missing items take the degradation path
4. Execute      → output step by step, tagging the source of each piece of information
5. Gated output → conclusion directly answers the question + actionable advice + confidence
```

## 🔮 Boundaries

- **No framework for simple tasks**: when the task is simple and clear or the user wants a direct answer, skip the framework and answer directly
- **No framework when information is severely missing**: if even framework selection cannot be determined, ask clarifying questions first (degradation Level 3+)
- **Navigation and computation only, no execution**: this skill provides methodology selection, reasoning frameworks, and calculation tools; actual code changes and security scans are done by executor skills (code review → diting, SAST → tiangang)
- **No parallel use of exclusive pairs**: Lean Canvas ↔ Startup Canvas pick one; ICE is rough screening only — running it alongside RICE produces redundant output
